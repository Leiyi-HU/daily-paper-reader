## 摘要
主流的视觉-语言-动作（VLA）模型主要在马尔可夫假设下根据当前观测预测动作，因此在长时程、时间依赖的任务中表现不佳。现有的记忆增强VLA要么扩展观测窗口，要么从记忆库中检索历史作为辅助的策略端上下文。然而，它们将记忆置于VLA推理的原生潜在嵌入空间之外，阻碍了历史经验与多模态推理和动作生成的流畅交织。为此，我们提出了LaMem-VLA，一种潜在记忆原生的框架，将历史经验重构为潜在记忆令牌，并直接将其与VLA推理交织。其核心是，LaMem-VLA引入了四个协同组件：（i）策展器，将历史经验组织成互补的短期和长期记忆库；（ii）搜索器，利用多模态认知查询两个记忆库以检索上下文相关的证据；（iii）压缩器，将检索到的证据重构为紧凑的短期和长期潜在记忆令牌；（iv）织布器，将这些记忆令牌与当前观测和指令注入到一个连续的嵌入序列中。通过在同一连续潜在空间中表示、检索和消费历史经验，LaMem-VLA使记忆能够直接参与VLA推理，并在有界上下文下指导动作生成。在SimplerEnv和LIBERO上的大量实验证明了我们LaMem-VLA的优越性。

## Abstract
Mainstream Vision-Language-Action (VLA) models predict actions primarily from the current observation under a Markovian assumption, thus struggling with long-horizon, temporally dependent tasks. Existing memory-augmented VLAs either expand the observation window or retrieve history from the memory bank as auxiliary policy-side context. However, they leave memory outside the native latent embedding space of VLA reasoning, preventing historical experience from being fluidly interleaved with multimodal reasoning and action formation. To this end, we introduce LaMem-VLA, a latent-memory-native framework that reconstructs historical experience into latent memory tokens and directly interweaves them with VLA reasoning. At its core, LaMem-VLA introduces four coordinated components: (i) a curator that organizes historical experience into two complementary short-term and long-term memory vaults; (ii) a seeker that queries both vaults using the multimodal cognition to retrieve context-relevant evidence; (iii) a condenser that reconstructs the retrieved evidence into compact short-term and long-term latent memory tokens; and (iv) a weaver that injects these memory tokens with the current observation and instruction into one continuous embedding sequence. By representing, retrieving, and consuming historical experience entirely in the same continuous latent space, LaMem-VLA enables memory to directly participate in VLA reasoning and guide action generation under a bounded context. Extensive experiments on SimplerEnv and LIBERO demonstrate the superiority of our LaMem-VLA.

## 1. 论文的核心问题与整体含义

- **研究动机**：主流视觉-语言-动作（VLA）模型在马尔可夫假设下，仅依据当前观测预测动作，忽略了历史状态转移、已完成子任务和任务进度等时间依赖信息，导致在**长时程、时间依赖的机器人操作任务**中性能不佳（作者称之为“时间短视偏差”）。
- **现有方法的不足**：
  - 扩展观测窗口或输入视频序列：上下文长度增长带来计算/存储开销，且固定窗口存在记忆上限。
  - 外部记忆库检索：历史记忆存储于模型原生 token 空间之外，作为策略侧辅助上下文被消费，无法与 VLA 内部的多模态推理、指令理解和动作意图形成过程流畅交织。
- **核心研究问题**：历史经验能否表示为**上下文原生的潜在记忆**，与当前观测、指令和动作查询在同一连续潜在空间中存储、检索和消费？
- **整体含义**：论文提出 LaMem-VLA，将记忆直接嵌入 VLA 的推理序列，使历史经验参与模型原生推理过程，从而提升长时程操作的时序感知能力。

## 2. 方法论

### 2.1 核心思想
- 将机器人历史经验组织为**短期视觉记忆**（保存当前情节的视觉证据）和**长期语义记忆**（保存任务进度、动作连续性等语义信息）。
- 两条记忆流均被重构为**固定长度的潜在记忆 token**，并直接插入 VLA 的输入序列，与当前视觉 token、语言指令 token、动作查询 token 在同一嵌入空间中共同参与自注意力计算。

### 2.2 四个协调组件
1. **Latent Memory Curator（潜在记忆策展器）**
   - 短期记忆库 \(M_{\text{short}}\)：存储由 SE-bottleneck 压缩模块从当前视觉 token \(X_t\) 蒸馏出的键值对 \((k_s, v_s)\)，键为均值池化后的向量。
   - 长期记忆库 \(M_{\text{long}}\)：直接写入动作隐藏状态 \(H_{\text{action}}\)（由动作查询 token 输出得到），用于追踪任务进度。
   - 更新策略：当单元数超过容量 \(L\) 时，计算相邻键的余弦相似度，合并最冗余的相邻对（键和值分别取平均）。

2. **Latent Memory Seeker（潜在记忆搜索器）**
   - 基于当前视觉 token \(X_t\) 和指令 token \(I\)，通过轻量查询构建器 \(B\) 生成上下文感知查询 \(Q_t \in \mathbb{R}^{K_q \times C}\)。
   - 使用均值池化查询 \(q_t\) 与两个记忆库中的键计算余弦相似度，分别检索 Top-\(K\) 个最相关单元，得到短期证据 \(Z_{\text{short}}\) 和长期证据 \(Z_{\text{long}}\)。

3. **Latent Memory Condenser（潜在记忆压缩器）**
   - 引入可学习的短期记忆槽 \(T_s\) 和长期记忆槽 \(T_l\)，通过轻量 Transformer 风格的 memory former，将检索到的冗长证据压缩为固定长度的潜在记忆 token：
     \[
     M_{\text{short}} = F_v([Q_t; Z_{\text{short}}; T_s])[-L_s:], \quad 
     M_{\text{long}} = F_c([Q_t; Z_{\text{long}}; T_l])[-L_l:]
     \]
   - 固定长度保证注入记忆的上下文开销不随检索数量增长。

4. **Latent Memory Weaver（潜在记忆织布器）**
   - 构造记忆增强的 VLA 输入序列：
     \[
     S_t = [M_{\text{short}}; M_{\text{long}}; X_t; I; Q_{\text{action}}]
     \]
   - 该序列经 VLM 处理后得到记忆接地的动作 token \(Z_{\text{action}}\)，再送入**扩散动作专家**生成动作序列。

### 2.3 训练与推理
- 训练损失为扩散模型的 MSE 噪声预测损失：
  \[
  \mathcal{L}_{\text{action}} = \mathbb{E}_{n,\epsilon}\left[\left\| \epsilon - \epsilon_\theta(a_{t:t+H-1}^{(n)}, n, Z_{\text{action}}) \right\|_2^2\right]
  \]
- 推理时使用 DDIM 采样，10 步去噪生成 7-DoF 连续动作。

## 3. 实验设计

### 3.1 基准与数据集
- **SimplerEnv-Bridge**（WidowX 机器人）：
  - 标准 Bridge 协议，在 Bridge v2 数据集上训练 50k 步。
  - 任务：Put Spoon on Towel、Put Carrot on Plate、Stack Cube、Put Eggplant in Basket，每任务 24 次 trial。
- **LIBERO**（Franka 机器人）：
  - 五个 suite：Spatial、Object、Goal、Long-10、Long-90（其中 Long-90 含 90 个任务）。
  - 遵循 OpenVLA 协议，每个任务 50 条演示；Spatial/Object/Goal 各训练 20k 步，Long-10 和 Long-90 联合训练 40k 步。
  - 每任务 50 次 rollout 报告成功率。

### 3.2 对比方法
- 包括 RT-1-X、OpenVLA、TraceVLA、SpatialVLA、Magma、CogACT、π0、DreamVLA、ThinkAct、CronusVLA、MemoryVLA、SemanticVLA、Diffusion Policy、Octo、UniACT、CoT-VLA、π0-FAST、LARA 等。
- 重点关注与强基线 MemoryVLA、CogACT、π0 的对比。

### 3.3 主要实验结果
- **SimplerEnv-Bridge**：平均成功率 73.9%，优于 CogACT（57.3%）16.6 点，优于 π0（69.2%）4.7 点。
- **LIBERO**：平均成功率 97.6%，优于 MemoryVLA（96.5%）1.1 点，优于 CogACT（93.2%）4.4 点；在 Long-10 和 Long-90 上分别比 MemoryVLA 高 2.4 和 1.4 点。

### 3.4 消融实验
- **双记忆有效性**：w/o Dual Memory（无记忆）→ SimplerEnv 57.3%，LIBERO-90 92.1%；w/o Short-term Memory → 65.6%/95.4%；w/o Long-term Memory → 64.6%/94.8%；完整模型 → 73.9%/97.0%。
- **潜在原生记忆 vs 策略侧条件**：策略侧记忆（71.9%/94.8%）和原始检索条件（69.8%/95.1%）均不如完整模型（73.9%/97.0%）。
- **检索数量 \(K\)**：K=2/4/8/12 对比，K=8 最优（73.9%/97.0%），过多或过少均下降。
- **记忆 token 数量 \(L_s, L_l\)**：分析不同 \(L_s\)（2~32）和 \(L_l\)（1~8）的影响，默认 \((L_s, L_l)=(8,4)\) 为性能与效率平衡。

## 6. 主要结论与发现

- 将历史经验表示为**双尺度潜在记忆**并注入 VLA 输入序列，能显著提升长时程操作任务的成功率。
- 短期视觉记忆和长期语义记忆具有**互补性**：移除任一均导致性能下降，移除两者下降最大。
- **潜在原生记忆集成**优于传统策略侧记忆条件或直接拼接原始检索证据，说明记忆参与模型内部推理是关键。
- 检索数量 \(K\) 和记忆 token 数量 \(L_s, L_l\) 存在最优区间，过多或过少均不利。
- 在 SimplerEnv 和 LIBERO 上达到 SOTA，证明该范式为构建具有时序感知的 VLA 系统提供了可行方向。

## 7. 优点

- **创新性**：首次将机器人记忆作为“上下文原生潜在记忆”，在同一连续嵌入空间中完成存储、检索和消费，突破了以往辅助策略侧记忆的架构限制。
- **设计清晰**：四个模块（curator/seeker/condenser/weaver）分工明确，符合认知科学中短期/长期记忆的互补思想。
- **有界上下文**：通过固定长度的记忆 token，使记忆增强不会无限扩展上下文长度，兼顾性能与效率。
- **实验严谨**：在多个基准和任务上验证，消融实验覆盖主要设计选择，对比方法多且结果报告清晰。
- **可扩展性**：记忆机制不依赖特定骨干，可与现有 VLA 和扩散/流匹配专家结合。

## 8. 不足与局限

- **仅模拟验证**：作者明确说明当前版本的所有实证均来自模拟环境，真实世界实验尚未完成（论文提到将在下一版本补充）。
- **泛化风险**：在模拟基准上的成功未必能完全迁移到真实机器人；真实场景中的视觉多样性、动态干扰和硬件噪声未考虑。
- **记忆依赖的局限性**：检索依赖当前多模态 query，若当前观测存在视觉歧义或干扰，检索可能不可靠（论文在相关工作部分也承认外部记忆检索的类似缺陷未完全解决）。
- **计算成本**：7B 骨干 + 300M 动作专家 + 双记忆处理模块，训练需要 8×H800 大规模 GPU，资源要求较高；推理时记忆检索和压缩也会引入额外延迟。
- **长期记忆形式单一**：长期记忆仅存储动作隐藏状态，可能无法完整保留更丰富的语义/因果信息；实际效果与更高层的记忆表示尚待比较。
- **消融范围有限**：部分消融结果仅在 SimplerEnv 和 LIBERO-90 上报告，未覆盖全部 LIBERO suite；未报告多次随机种子的统计显著性。

## 摘要
端到端视觉语言导航（VLN）利用因果视觉语言模型将指令和以自我为中心的观察直接映射到动作，但标准的行为克隆仅监督下一个动作，并不明确鼓励策略状态对未来视觉结果具有预测性，从而限制了长时程决策。一项特权输入诊断表明，获取专家轨迹的未来图像能显著提升导航性能，这表明未来观察包含丰富、可操作的线索，尽管此类输入在部署时不可用。受此信号启发，我们提出未来状态条件化VLN（FSC-VLN），一种可部署模型，它通过未来查询令牌增强因果策略，并利用仅训练时的未来状态监督，将未来观察中的信息蒸馏到策略状态中。具体而言，在训练期间，我们将未来查询表示对齐到未来Δ步的冻结视觉嵌入，而推理时仅需过去和当前的观察。该设计保持基线推理模式，仅增加两个学习的前缀令牌，意味着极小的额外开销。在R2R val-unseen上，FSC-VLN在两种训练数据设置下相比StreamVLN风格基线提升了SR/OSR/SPL，并在长时程回合中收益更大；消融实验进一步支持了将未来查询与动作查询分离的双查询设计。

## Abstract
End-to-end vision-language navigation (VLN) with causal vision-language models maps instructions and egocentric observations directly to actions, but standard behavior cloning supervises only the next action and does not explicitly encourage the policy state to be predictive of future visual outcomes, limiting long-horizon decision making. A privileged-input diagnostic shows that access to an expert-trajectory future image can substantially improve navigation, indicating that future observations contain rich, actionable cues, though such inputs are unavailable at deployment. Motivated by this signal, we propose Future-State-Conditioned VLN (FSC-VLN), a deployable model that augments a causal policy with a future-query token and uses training-only future-state supervision to distill information from future observations into the policy state. Concretely, during training we align the future-query representation to a frozen visual embedding $Δ$ steps ahead, while inference requires only past and current observations. This design preserves the baseline inference pattern and adds only two learned prefix tokens, implying minimal overhead. On R2R val-unseen, FSC-VLN improves SR/OSR/SPL over a StreamVLN-style baseline under two training-data regimes, with larger gains on long-horizon episodes; ablations further support the dual-query design that separates future and action queries.

## 1. 论文的核心问题与整体含义

**研究动机与背景：**
- 端到端视觉语言导航（VLN）任务要求智能体根据自然语言指令，在连续环境中执行一系列底层动作以到达目标位置。
- 主流方法采用因果视觉语言模型（如基于 Qwen2 的 StreamVLN、NaVid、NaVILA 等），将指令、当前观测和历史观测编码为多模态 token 序列，通过行为克隆（Behavior Cloning）自回归生成动作。
- **核心问题**：标准行为克隆只监督"下一个动作"，未显式要求策略的内部状态能预测未来视觉结果。在长时程连续导航中，局部合理的动作会逐渐累积偏差，导致轨迹漂移，而下一动作监督无法提供对未来视觉状态的直接约束。
- **关键诊断**：作者设计了"特权输入诊断"实验——在训练和测试时都将专家轨迹未来 Δ=32 步的图像额外输入策略。结果显示 SR 从 29.96% 大幅提升至 71.77%，证明**未来观测包含丰富、可操作的导航线索**（尽管部署时不可用）。

**整体含义**：论文的核心研究问题是——*"能否在训练时利用未来观测信息、推理时不依赖任何未来输入，来提升可部署在线导航策略的性能？"* 作者通过将未来视觉信息蒸馏为策略内部的预测性表征，验证了"训练期未来状态监督"这一思路的可行性。

## 2. 论文提出方法论：FSC-VLN

**核心思想**：在端到端因果 VLM 导航策略中插入 **未来查询 token（qF）** 和 **动作查询 token（qA）**，训练时让 qF 的隐状态对齐"未来 Δ 步观测的冻结视觉嵌入"，从而将未来视觉信息通过因果注意力注入动作生成过程，而推理时只需过去和当前观测。

**关键技术细节：**

1. **模型结构**：
   - 冻结视觉编码器：SigLIP-SO400M + 两层 MLP 投影器（MLP 也冻结），将每帧图像编码为 N² 个视觉 token。
   - 因果策略：Qwen2-7B 因果 Transformer，在线上下文为 Ct = [指令 token + 历史/当前视觉 token]。
   - 序列组织：`Xt = [Ct, qF, qA, at]`，即上下文 → 未来查询 → 动作查询 → 动作 token。

2. **双查询设计**：
   - **未来查询 qF**：其隐状态 hFt 在训练时被未来目标监督，通过因果注意力可聚合指令和视觉上下文。
   - **动作查询 qA**：位于 qF 之后，可通过因果注意力查看 qF，其隐状态 hAt 直接作为第一个动作 token 的解码前缀。
   - 这形成了 **qF → qA → at** 的因果路径，使动作生成显式条件于未来预测表征。

3. **未来目标构建**：
   - 训练时取专家轨迹中当前步后 Δ=32 步的观测图像 ot+Δ（若超出轨迹长度则使用最后一帧）。
   - 未来图像经共享冻结 SigLIP + MLP 编码，通过 stop-gradient（停止梯度）得到目标嵌入，再经 mean pooling 聚合成单个 d 维向量 z*。
   - 仅在线上下文图像应用随机外观增强，未来目标图像用标准预处理，以保证目标稳定。

4. **未来状态对齐损失**：
   - 为降低高维嵌入匹配难度，引入投影函数 g: R^d → R^d′（d′ ≪ d），在低维投影空间计算 ℓ1 距离：
   - **L_future = ‖ g(ĥFt) − g(z*t+Δ) ‖₁**
   - stop-gradient 确保梯度不流入冻结视觉编码器，仅更新 Transformer 参数和查询嵌入。

5. **总训练目标**：
   - **L_total = L_LM + λF·L_future**，其中 L_LM 为标准全词表交叉熵（动作 token 的下一 token 预测），λF = 0.1。
   - 语言模型头（bias-free 线性层）与查询嵌入共同优化；视觉编码器和 MLP 投影器保持冻结。

6. **推理时**：
   - 未来目标分支被完全丢弃，无未来图像、无辅助编码器、无额外策略前向。
   - 在线上下文和两个查询 token 在单次因果 prefill 中联合处理，动作 token 后自回归解码。推理仅比基线多 2 个前缀 token，开销几乎可忽略。

## 6. 论文的主要结论与发现

1. **特权诊断结论**：专家轨迹未来图像作为额外输入能大幅提升导航性能（SR +41.81 个百分点），证实未来观测富含可操作线索——但该设置不可部署，仅作为动机验证。
2. **FSC-VLN 有效**：在两种训练数据体制下，FSC-VLN 均全面提升了 SR/OSR/SPL：
   - R2R+RxR 体制：SR +1.47、OSR +3.27、SPL +1.11 个百分点；
   - 扩充数据体制：SR +0.98、OSR +1.04、SPL +0.85 个百分点。
3. **增益集中于长视界**：短视界 episode 的指标几乎不变（±0.46 以内），长视界 episode 上 SR 提升最高达 +3.85 个百分点、OSR 最高 +7.15 个百分点、SPL 最高 +3.70 个百分点——这与"长时程决策需要预测性状态"的核心假设一致。
4. **双查询设计必要**：移除独立动作查询后，SR（45.79%→45.19%）和 SPL（42.81%→41.76%）下降，且长视界下降更明显，说明未来的预测表征需要经由独立动作查询"转译"为高效逐步决策。
5. **零推理结构变化**：在单次因果 prefill + 自回归动作解码的推理范式下，仅多两个前缀 token，即可获得导航收益。

## 7. 优点

1. **动机扎实、问题定义清晰**：通过特权诊断实验先验证"未来信息是否有用"，再从可部署视角提出方法，逻辑链条严谨。
2. **方法极简且推理开销极小**：只增加两个可学习前缀 token，不修改 Transformer 结构、不增加视觉编码器推理负担、不需要未来图像生成器或第二前向，实际部署友好。
3. **因果设计巧妙**：qF（未来预测）→ qA（动作条件）→ at 的序列组织，让未来信息通过因果注意力自然注入动作解码，与 Transformer 的因果机制契合。
4. **未来目标设计稳健**：采用冻结编码器 + stop-gradient + 外观增强隔离（只增强在线图像），提供稳定训练目标，且仅用 ℓ1 对齐、低维投影，训练开销低。
5. **实验分析深入**：长短视界分层揭示增益分布机理；消融实验验证双查询的必要性，而非仅报告整体指标。

## 8. 不足与局限

1. **实验覆盖有限**：
   - 仅在 R2R val-unseen 上报告结果，缺少 R2R test-unseen、RxR 测试集、其他环境（如 Room-across-Room 的多语言设置）的验证；
   - 仅对比 StreamVLN 一个基线，未与当前 SOTA（NaVid、NaVILA、Uni-NaVid、MapNav、JanusVLN）横向比较，方法在整体领域中的定位不明确；
   - 仅使用 Qwen2-7B 一个骨干，泛化性未验证。

2. **偏差风险**：
   - **专家轨迹偏差**：未来目标来自专家轨迹，与智能体在真实 on-policy 执行中可能看到的未来图像存在分布偏移（作者在 Limitation 中自认）；
   - **固定 Δ 不灵活**：Δ=32 步对所有场景和轨迹长度固定，可能对短轨迹或复杂场景不当；
   - **评测集偏差**：长短视界分层基于起点-目标地理距离，但未分析更细粒度因素（如障碍物密度、指令复杂度）的影响。

3. **应用限制**：
   - 方法主要针对**离散动作空间**（↑←→STOP）的 VLN-CE 设置，推广到连续低层控制（如机器人真机部署）尚需验证；
   - 目标聚合采用简单 mean pooling，可能丢失空间细粒度信息；
   - 训练仍依赖行为克隆范式，未解决 VLN 中泛化到全新环境的根本挑战，数据扩充后的增益明显减小（SR 增益从 1.47 降至 0.98），说明在大数据体制下该方法带来的边际收益有所收敛。

4. **算力信息不完整**：未披露 GPU 型号和训练时长，复现成本难以精确评估。

## 摘要
当前的视觉-语言-动作（VLA）模型在机器人操作方面表现出色，但由于依赖即时观察，在面对需要长期记忆和推理的非马尔可夫任务时常常遇到困难。现有解决方案面临一个“频率-能力悖论”：更强的推理模型对于实时控制而言速度过慢，而速度更快的模型则缺乏足够的推理能力。为了解决这种架构上的错配，我们提出了HiMe，一个层级具身记忆框架，它将具身智能解耦为用于执行的高频执行器、用于工作记忆的哨兵以及用于长期策略的规划器。我们还引入了一个基于跨模态语义图式和主动管理机制的动态知识系统，使机器人能够通过“添加、更新和删除”操作来保持记忆的可塑性。这种层级设计有效平衡了实时执行与慢速思考规划之间的冲突，显著提高了长时程任务的成功率。实验表明，该方法不仅优于平面记忆基线，还展现出了一种新颖的能力：能够根据人类偏好自我修正其内部知识。

## Abstract
Current Vision-Language-Action (VLA) models excel at robotic manipulation but often struggle with non-Markovian tasks requiring long-term memory and reasoning due to their reliance on immediate observations. Existing solutions face a ''frequency-competence paradox,'' where stronger reasoning models are too slow for real-time control, while faster models lack sufficient reasoning capabilities. To resolve this architectural misalignment, we propose HiMe, a Hierarchical Embodied Memory framework that decouples embodied intelligence into a high-frequency Executor for execution, a Sentry for working memory, and a Planner for long-term strategy. We also introduce a dynamic knowledge system based on cross-modal semantic schemas and active management mechanisms, allowing robots to maintain memory plasticity through ''Add, Update, and Delete'' operations. This hierarchical design effectively balances the conflict between real-time execution and slow thinking planning, significantly improving success rates in long-horizon tasks. Experiments demonstrate that this approach not only outperforms flat memory baselines but also exhibits the novel ability to self-correct its internal knowledge based on human preferences.

## 二、论文提出的方法论

### 1. 核心思想：三层级具身记忆架构

借鉴人类认知的多存储结构（multi-store model），将机器人智能解耦为三个功能层：

| 模块 | 对应记忆类型 | 频率 | 角色 |
|------|------------|------|------|
| Executor（执行器） | 瞬态记忆 \( \mathcal{T}_t \) | 高频（2 Hz） | 感知-运动协调，实时控制 |
| Sentry（哨兵） | 工作记忆 \( \mathcal{W}_t \) | 中频（定期查询） | 监测子任务进度，判定“完成/未完成”，触发规划 |
| Planner（规划器） | 情景记忆 \( \mathcal{E}_t \) | 低频（按需调用） | 检索记忆、更新记忆、重新规划子任务序列 |

### 2. 记忆的知识系统组织

- **“记什么？”——跨模态语义图式（Cross-modal Semantic Schemata）**
  - 情景记忆由两部分组成：
    - **语境记忆（Contextual Memory）**：多模态键值存储 \( \mathcal{M}_t \)，同时保存视觉图像（如箱中物体状态）与高密度文本描述（如归属关系、用户偏好、空间约束）；
    - **程序记忆（Procedural Memory）**：有序的语言子目标列表 \( \mathcal{E}_t^p = \{\tau_i\}_{i=1}^N \)，每个子目标带有“active / pending / done”状态标签。
  - 这种设计使 Planner 能检索到纯像素空间中不可见的信息（如“Alice 的玩具是鸭子”）。

- **“怎么记？”——主动管理机制（Active Management）**
  - 引入三种显式记忆操作：
    - **Add（添加）**：插入新观测事实或新用户偏好；
    - **Update（更新）**：修正过时条目（如物体位置变化）；
    - **Delete（删除）**：移除冗余或冲突信息。
  - 该机制使记忆系统具有“可塑性”（plasticity），可随环境和用户意图演化。

### 3. 层级策略分解（数学形式）

将总体策略形式化为三层交互：

- **底层执行器**：
  \[
  a_t \sim \pi_e(a_t \mid o_t, \tau_t)
  \]
  假定给定当前活动子目标 \( \tau_t \) 时，动作只依赖当前观测，保持无状态、计算高效。

- **敏捷哨兵**（门控函数）：
  \[
  u_t = \begin{cases}
  \mathbb{I}[\pi_s(\mathcal{W}_t, \tau_t) > \delta], & \text{if } t \equiv 0 \pmod{n_m} \\
  0, & \text{otherwise}
  \end{cases}
  \]
  哨兵在间隔 \( n_m \) 步检查一次工作记忆，只有满足“完成/失效”条件时（\( u_t = 1 \)）才唤醒 Planner，否则维持现有记忆不变。

- **推理规划器**：
  - **上下文检索**：
    \[
    q_t = f_{\text{enc}}(l, \mathcal{W}_t), \quad \mathcal{M}_{\text{ret}} = \text{TopK}(\mathcal{E}_t^c, q_t)
    \]
  - **记忆更新与重规划**：
    \[
    (\mathcal{E}_t^{c+1}, \mathcal{E}_t^{p+1}) \leftarrow \pi_p(l, \mathcal{W}_t, \mathcal{M}_{\text{ret}}, \mathcal{E}_t^p)
    \]
    同步更新语境记忆（Add/Update/Delete）和程序记忆（生成新的子目标序列）。

### 4. 实现细节

- **Planner**：GPT-4o（多模态推理强），实验中另用 Qwen3-VL-30B 验证可复现性；

## 六、论文的主要结论与发现

1. **分层记忆显著优于平坦记忆**：HiMe 平均任务成功率达 90%，远超 Flat Memory（65%）和 Transient Memory（14%）。
2. **Sentry 的双重价值**：
   - **一致性**：防止 Planner 在子任务未完成时被高频临时噪声干扰，避免频繁任务切换（Transient Memory 14% → w/ Sentry 26%）；
   - **质量**：聚合子任务历史为结构化工作记忆，提供全局视角，减少幻觉和冗余重规划。
3. **主动管理比“存更多”更重要**：
   - FIFO 朴素淘汰会丢失早期关键信息（68%）；无管理保留全部历史虽好（86%）但有冗余冲突；主动管理（Add/Update/Delete）最优（90%）；
   - 跨模态记忆结合图像的空间保真度与文本的语义逻辑，优于纯文本或纯图像。
4. **效率优势显著**：相比 Flat Memory，HiMe 的 API 调用减少约 3 倍（如 Object Search 中 5.4 → 1.8），记忆命中率从 68% 提升至 94%。
5. **Sentry 的“保守”特性**：偏好不宣布完成（高 Precision、低 Recall），因此需要固定间隔的 Planner fallback 防止死循环。

## 七、优点

- **架构设计简洁且可解释**：三层解耦（Executor/Sentry/Planner）对应认知科学中的多存储记忆模型，逻辑清晰、动机充分。
- **有效解决“频率-能力悖论”**：让快模型做执行、轻量模型做监控、强模型只做低频规划，大幅摊销推理成本。
- **记忆组织有深度**：跨模态语义图式 + 主动 CRUD 管理，将记忆从“被动观测缓冲区”提升为“动态自进化知识系统”。
- **验证充分**：多角度消融（模块、模态、管理策略、容量、Planner 泛化、可扩展性）覆盖系统设计的关键维度；
- **实际部署可行**：兼容 GPT-4o 与开源 VLM，自部署延迟低（Qwen3-VL-30B 本地 P50 仅 6.83 s）；
- **代码开源**：提供 GitHub 链接，方便后续研究。

## 八、不足与局限

- **缺乏标准仿真 benchmark**：论文在真机环境评估，未与现有标准仿真基准对齐，难以进行完全受控的横向对比，也不利于基准级可复现性。
- **任务技能覆盖有限**：主要依赖 pick-and-place 等简单操作原语，未涉及更复杂、更灵巧的操作技能。
- **长时程极限未充分表征**：论文自述尚未完全刻画极长地平线、更大环境和长时间部署下的性能表现。
- **记忆扩展性仍有挑战**：多轮扩展实验显示，随着轮次增加（1→3 轮），记忆规模增长（5.5→14.0），但任务成功率显著下降（92.5%→66.7%），说明仅靠记忆增长不足以维持长程一致性，如何消除陈旧记忆干扰仍是开放问题。
- **对大型闭源模型有依赖**：主实验使用 GPT-4o，虽然补充了开源 Planner 验证，但核心结论仍依赖特定模型的强语义推理能力。
- **Sentry 低召回率问题**：容易漏检“完成”信号，需依赖固定间隔 fallback 防止死循环，说明监控模块本身存在可靠性边界。

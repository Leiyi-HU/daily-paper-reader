## 摘要
目标导航要求具身智能体在室内环境中定位并到达指定对象类别的实例。最近的免训练方法利用视觉-语言模型（VLM）进行开放词汇语义推理，但通常在情景协议下进行评估，该协议在每个情景后重置所有场景特定状态。我们引入了跨情景目标导航，其中智能体在相同场景中重复操作，仅保留自我获取的经验，并保持其模型参数固定。为了支持经验重用，我们提出了\method，一种具有持久分层视觉-拓扑记忆（VTM）的免训练VLM导航框架。VTM在房间和对象级别组织场景知识，并通过由粗到精的匹配检索相关经验，仅在记忆与当前观察一致时提供作为软指导的记忆。保守的执行守卫进一步减轻了振荡、阻塞运动和过早停止。在受控的相同场景协议下，我们在三个基准测试HM3D v0.1、HM3D v0.2和MP3D上评估\method，并将其与增强的WMNav基线（增加了跨情景文本记忆，同时保持VLM主干和动作流程相同）进行比较。\method在所有三个基准测试中均达到最佳性能，展示了结构化视觉-拓扑经验重用跨数据集的有效性和鲁棒性。

## Abstract
Object-goal navigation requires an embodied agent to locate and reach an instance of a specified object category in an indoor environment. Recent training-free approaches leverage vision-language models (VLMs) for open-vocabulary semantic reasoning, but are typically evaluated under an episodic protocol that resets all scene-specific state after each episode. We introduce Cross-Episode Object-Goal Navigation, in which an agent repeatedly operates in the same scene, retains only self-acquired experience, and keeps its model parameters fixed. To support experience reuse, we present \method, a training-free VLM navigation framework with a persistent hierarchical Visual-Topological Memory (VTM). The VTM organizes scene knowledge at room and object levels and retrieves relevant experience through coarse-to-fine matching, providing memory as soft guidance only when it agrees with current observations. A conservative execution guard further mitigates oscillations, blocked motions, and premature stopping. Under a controlled same-scene protocol, we evaluate \method{} on three benchmarks, HM3D v0.1, HM3D v0.2, and MP3D, and compare it with a strengthened WMNav baseline augmented with cross-episode textual memory, while keeping the VLM backbone and action pipeline identical. \method{} achieves the best performance across all three benchmarks, demonstrating the effectiveness and robustness of structured visual-topological experience reuse across datasets.

- **关键缺陷**：现有方法通常在**情景协议（episodic protocol）** 下评测——每个测试回合结束后，场景特定状态（如智能体位置、内存、探索记录）被全部重置。这导致智能体**无法在同一场景中跨回合积累与复用经验**，与真实世界机器人反复在固定环境中执行任务的实际场景存在偏差。
- **本文提出的新任务**：引入**跨情景目标导航（Cross-Episode Object-Goal Navigation）**——智能体在同一场景中重复执行任务，仅保留**自获取的经验**，且**模型参数完全固定**（不进行任何微调或在线学习）。
- **整体含义**：本文首次系统性探索"经验重用"如何帮助免训练VLM导航智能体在同一环境中持续提升表现，填补了现有评测协议与真实应用场景之间的鸿沟。

## 2. 方法论：VTM-Nav

### 核心思想
- 构建一个**持久性分层视觉-拓扑记忆（Visual-Topological Memory，VTM）**，在**房间级别**和**物体级别**两个粒度上组织场景知识；
- 通过**由粗到细（coarse-to-fine）的匹配机制**检索与当前观察最相关的历史经验；
- 记忆仅作为**软指导（soft guidance）** 参与决策——只有在记忆内容与当前视觉观察**一致**时才被激活，避免过时或错误记忆干扰导航；
- 引入**保守执行守卫（Conservative Execution Guard）**，抑制三种常见导航故障：振荡（oscillations）、阻塞运动（blocked motions）和过早停止（premature stopping）。

### 关键技术细节
| 模块 | 功能 |
|------|------|
| 房间级记忆 | 存储各房间的语义描述与进入/退出线索，帮助智能体快速定位目标可能出现的区域 |
| 物体级记忆 | 记录目标物体及相似物体的具体观察位置、视角特征，支持精确到达 |
| 粗到细匹配 | 先进行房间级粗匹配缩小搜索范围，再进行物体级细匹配确定具体路径 |
| 一致性子门控 | 记忆指导仅在"记忆与当前感知不冲突"时生效，降低幻觉与误召回风险 |
| 执行守卫 | 检测并中断循环路径、停滞状态和提前终止行为，保证导航动作的连续性 |

### 算法流程（文字描述）
1. 智能体在场景中探索，将访问过的房间和观察到的物体分别编码为**房间节点**和**物体节点**，存入持久记忆库；
2. 每步决策时，先用当前观察视图粗匹配房间级记忆，定位候选房间；
3. 再在候选房间中细匹配物体级记忆，获得历史经验中的方向/距离提示；
4. 通过一致性校验后，将记忆提示与VLM的实时语义推理融合，生成动作；
5. 执行守卫监控动作流，对振荡、阻塞、过早停止进行纠正；
6. 当前回合结束后，所有场景经验持久保存，供后续回合使用，但**模型权重始终保持不变**。

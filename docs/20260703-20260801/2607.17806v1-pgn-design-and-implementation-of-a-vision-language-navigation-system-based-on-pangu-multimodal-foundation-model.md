## 摘要
视觉-语言导航（VLN）要求具身智能体解释自然语言指令，并从按时间顺序排列的视觉观察中预测动作。将多模态大语言模型适配到VLN需要视觉-语言对齐、紧凑的时间输入、动作空间接地以及在目标硬件上的稳定训练。本技术报告介绍了PGN（盘古导航器），一个基于OpenPangu-7B构建的离线VLN动作预测系统。训练分两个阶段进行。首先，PGMM通过训练Q-Former和两层MLP投影器，将冻结的EVA-ViT-G/14视觉编码器与冻结的语言主干对齐。其次，PGN使用五观察窗口、依赖于周期的时序采样以及先推理后动作的输出格式，将对齐后的模型适配到专家导航轨迹；此阶段冻结对齐的视觉通路，并更新三个结构词元嵌入和LoRA适配器。该实现结合了混合精度计算、选择性FP32计算以及八个昇腾910B NPU上的DeepSpeed ZeRO-2。在500条留出专家轨迹上的教师强制开环评估中，V9报告了62.29%的归一化动作匹配（NAM）和100.00%的非空率（NER）。这些指标量化了离线专家动作对齐，而非闭环导航成功；评估误差累积、路径效率和目标完成情况仍是未来工作。

## Abstract
Vision-Language Navigation (VLN) requires an embodied agent to interpret a natural-language instruction and predict actions from temporally ordered visual observations. Adapting a multimodal large language model to VLN requires visual-language alignment, compact temporal inputs, action-space grounding, and stable training on the target hardware. This technical report presents PGN (Pangu Navigator), an offline VLN action-prediction system built on OpenPangu-7B. Training proceeds in two stages. First, PGMM aligns a frozen EVA-ViT-G/14 vision encoder with the frozen language backbone by training a Q-Former and a two-layer MLP projector. Second, PGN adapts the aligned model to expert navigation trajectories using five-observation windows, epoch-dependent temporal sampling, and a reasoning-then-action output format; this stage freezes the aligned visual pathway and updates three structural-token embeddings and LoRA adapters. The implementation combines mixed-precision computation, selective FP32 computation, and DeepSpeed ZeRO-2 on eight Ascend 910B NPUs. Under teacher-forced, open-loop evaluation on 500 held-out expert trajectories, V9 reports a 62.29% Normalized Action Match (NAM) and a 100.00% Non-empty Rate (NER). These metrics quantify offline expert-action alignment rather than closed-loop navigation success; evaluating error accumulation, path efficiency, and goal completion remains future work.

## 二、论文方法论

### 2.1 导航问题形式化定义

- 在每个时间步 t，模型接收自然语言指令 I 和一个包含五帧观测的有序窗口（当前观测 + 四个历史观测）：
  - **Ot = (o₍ₜ₋₄ₛ₎, o₍ₜ₋₃ₛ₎, o₍ₜ₋₂ₛ₎, o₍ₜ₋ₛ₎, oₜ)**，其中 s 为时间采样步长，窗口长度固定为5。
- 动作空间为四类语义动作：**A = {forward, left, right, stop}**（前进 0.25 米，转向 15 度/次）。
- 输出形式采用"**先推理、后动作**"的分解式生成：
  - **P(rₜ, aₜ | I, Oₜ) = P(rₜ | I, Oₜ) · P(aₜ | rₜ, I, Oₜ)**

### 2.2 模型组件架构

- **视觉编码器**：EVA-ViT-G/14（冻结），提取 224×224 图像的 patch 级特征。
- **Q-Former**：32 个可学习查询词元，通过交叉注意力生成固定尺寸的视觉表示。
- **两层 MLP 投影器**：将 768 维查询表示映射到 4096 维 OpenPangu-7B 嵌入空间。
- **语言骨干**：OpenPangu-7B（冻结），接收导航助手身份提示、指令和有序视觉词元。
- **结构词元**：3 个可学习的结构 token，分别标记图像开始、图像结束和帧边界。
- **LoRA 适配器**：注入语言模型，实现导航任务的参数高效微调。

### 2.3 两阶段训练流程

**阶段一：视觉-语言对齐预训练（PGMM）**

- 使用 Microsoft COCO 和 Visual Genome 的图像-标题配对数据；
- EVA-ViT-G/14 与 OpenPangu-7B 保持冻结；
- 仅优化 Q-Former 和两层 MLP 投影器，实现图像条件文本生成能力。

**阶段二：导航任务适配**

- 使用专家轨迹数据（DAgger 采集管线）；
- **关键修正**：数据采集固定 β = 1，即纯专家策略采集 + 监督行为克隆，**并非迭代式 DAgger 训练**；
- 训练策略细节：
  - 五帧观测窗口从轨迹中采样，起始索引随 epoch 轮转：**istart = e mod s**；
  - 三阶段采样课程：(s, p) = (4, 0.1) → (6, 0.6) → (8, 0.2)，其中 p 为动作感知采样器用转向/停止样本替换前向主导样本的概率；
  - 冻结已对齐的视觉通路和基础语言模型，仅更新 3 个结构词元嵌入和 LoRA 适配器。

## 三、实验设计

### 3.1 数据集与场景

- **视觉-语言对齐阶段**：Microsoft COCO + Visual Genome（图像-标题对）；
- **导航训练数据**：DAgger 兼容模拟管线采集，清洗后含 **19,699 条导航轨迹、1,567,487 帧观测**；
- **评估数据**：500 条留出的专家轨迹验证集（来自 Habitat 模拟器）。

### 3.2 评估协议

- **教师强制、开环评估**：模型接收专家轨迹中固定的五帧观测窗口，预测动作后**不执行**该动作获取下一帧观测，直接与专家动作对照；
- **评估指标**：
  - **EM（Exact-string Match）**：生成响应与规范动作字符串完全一致；
  - **NAM（Normalized Action Match）**：归一化提取动作后与专家动作匹配；
  - **NER（Non-empty Rate）**：产生非空动作响应的比例。

### 3.3 对比方法

- **未与已发表的 VLN 系统进行对比**，论文明确声明结果不应被解释为与 SOTA 系统的比较；
- 横向上对比的是**自身模型多个版本**（V3、V5、V6、V8、V9）的开发迭代结果；
- **无消融实验**：推理后动作格式、身份提示、时间采样、动作感知采样均在同一开发周期引入，无法隔离各组件贡献。

## 六、主要结论与发现

1. **可行性验证**：两阶段训练策略（视觉对齐 → 导航适配）成功将 OpenPangu-7B 适配到离线 VLN 动作预测任务。
2. **性能表现**：V9 在 500 条留出轨迹上取得 **62.29% NAM** 和 **100.00% NER**；V8/V9 的逐轨迹 NAM 分布从早期版本的 10–30% 区间显著迁移至 50–80% 区间，表明系统整体改进了动作预测的准确性。
3. **硬件可行性**：在昇腾 910B NPU 上通过混合精度 + 选择性 FP32 + ZeRO-2 实现了 7B 级模型的稳定训练，验证了国产硬件上训练多模态大模型的可行性。
4. **明确边界**：离线动作对齐 ≠ 闭环导航成功。误差累积恢复能力、目标半径内停止能力、路径效率等关键导航能力尚未验证。

## 七、优点与亮点

1. **清晰的两阶段设计**：将视觉-语言对齐与导航任务适配解耦，逻辑清晰，易于调试和模块替换；
2. **结构化输入输出设计**：五帧观测窗口 + 结构边界 token + "推理后动作"输出格式，兼顾了时序感知与动作空间约束；
3. **硬件适配实践价值**：详细记录了在昇腾 NPU 上处理半精度数值不稳定问题的工程经验（选择性 FP32），对国产 AI 硬件生态具有参考意义；
4. **诚实的评估态度**：明确区分"离线专家动作对齐"与"闭环导航成功"，不夸大结果，指出了评估协议的边界；
5. **可复现性意识**：保留了 V6 的逐动作预测日志，支持结果复现；
6. **采样策略创新**：epoch 依赖的起始偏移轮转 + 动作感知采样，在固定窗口长度下增加了时序覆盖多样性。

## 八、不足与局限

### 实验覆盖不足

- **无闭环评估**：未在 Habitat 模拟器中执行预测动作，无法报告成功率（SR）、SPL、导航误差或 nDTW 等标准 VLN 指标；
- **无消融研究**：推理后动作格式、身份提示、时间采样、动作感知采样等组件贡献无法量化分离；
- **无横向对比**：未与 NavGPT、NavLLM 等已发表 VLN-LLM 系统比较，无法判断方法在领域内的相对水平；
- **V3 数据缺失**：区间计数总和仅 56，数据完整性存在问题；
- **V8/V9 细粒度信息缺失**：无逐动作错误分布，无法分析系统在哪些动作类别上表现薄弱。

### 偏差风险

- **行为克隆偏差**：β=1 的纯专家数据采集意味着模型只能学习专家分布，无法覆盖专家犯错或偏离轨迹后的恢复场景；
- **教师强制偏差**：训练和评估均使用专家观测历史，模型从未见过自身动作导致的观测分布偏移（exposure bias），在闭环中可能出现误差累积的级联失败；
- **版本对比混淆**：V5→V6→V8→V9 的差异是多项技术同时改变的结果，不能归因于单一因素。

### 应用限制

- **动作空间粒度有限**：仅 4 类离散语义动作，未覆盖速度控制、连续转向角度变化等更细粒度操作；
- **推理质量未评估**：虽然模型生成推理文本，但论文未单独衡量推理正确性，推理质量与实际动作决策之间的关系不明确；
- **单一数据集来源**：仅使用自家 DAgger 管线采集的室内轨迹数据，未在 R2R、RxR、VLN-CE 等公开基准上验证泛化能力；
- **语言覆盖有限**：未涉及多语言指令或复杂空间关系推理的评估。

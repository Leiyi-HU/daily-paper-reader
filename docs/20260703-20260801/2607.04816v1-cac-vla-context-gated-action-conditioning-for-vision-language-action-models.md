## 摘要
视觉-语言-动作（VLA）模型已成为通用机器人操作的一种有前途的范式，其中视觉-语言表示用于条件化连续动作生成。然而，这些表示并未明确针对动作条件化进行优化，使得动作专家需要弥合多模态理解与精确运动控制之间的差距。最近的动作推理方法引入了额外模块来生成显式动作计划或动作空间推理信号，证明了动作级指导的益处，但通常需要单独的动作生成框架。我们提出了CAC-VLA，一种上下文门控动作条件化框架，直接在VLM内学习一个轻量级的潜在动作接口。CAC-VLA不是生成可执行轨迹，而是训练VLM预测从粗到细的潜在动作，这些动作是从未来动作片段编码的结构化表示，并通过上下文门自适应地利用它们来条件化动作专家。这使得VLM原生的动作条件化成为可能，同时校准潜在动作指导对专家动作生成的影响。在LIBERO和LIBERO-Plus上的实验证明了CAC-VLA的有效性，在LIBERO上实现了98.3%的平均成功率，在LIBERO-Plus上实现了89.5%的成功率，表明上下文门控的潜在动作条件化是连续专家控制的有效接口。

## Abstract
Vision-Language-Action (VLA) models have become a promising paradigm for generalist robot manipulation, where visual-language representations are used to condition continuous action generation. However, these representations are not explicitly optimized for action conditioning, leaving the action expert to bridge the gap between multimodal understanding and precise motor control. Recent action-reasoning methods introduce additional modules to generate explicit action plans or action-space reasoning signals, demonstrating the benefit of action-level guidance but often requiring separate action-generation frameworks. We propose CAC-VLA, a Context-Gated Action Conditioning framework that learns a lightweight latent-action interface directly within the VLM. Instead of generating executable trajectories, CAC-VLA trains the VLM to predict coarse-to-fine latent actions, which are structured representations encoded from future action segments, and adaptively leverages them to condition the action expert via a context gate. This enables VLM-native action conditioning while calibrating the influence of latent-action guidance on expert action generation. Experiments on LIBERO and LIBERO-Plus demonstrate the effectiveness of CAC-VLA, achieving 98.3% average success rate on LIBERO and 89.5% LIBERO-Plus, suggesting that context-gated latent-action conditioning is an effective interface for continuous expert control.

## 2. 论文提出的方法论

- **核心思想**：让 VLM 预测**从粗到细（coarse-to-fine）的潜在动作**（latent actions），这些潜在动作不是直接可执行的轨迹，而是对未来动作片段的结构化编码；动作专家以这些潜在动作为条件生成最终连续动作，且通过**上下文门控（Context Gate）**自适应调节其影响。
- **整体框架**（式 1→式 2）：从标准 VLA 策略 `a = πθ(o, l)` 转变为 `z = fθ(o, l)`，然后 `a = πθ(o, l, z)`，其中 `fθ` 为 VLM 侧的潜在动作预测器。
- **潜在动作编码**：采用**有序动作分词器 OAT**（Ordered Action Tokenizer）编码未来动作片段得到原始潜在向量 `z_oat = OAT(a_{t:t+Hl-1})`，`Hl` 为潜在动作时域长度（latent-action horizon），可与专家动作时域长度 `He` 灵活不同。
- **VLM 原生的潜在动作预测**：
  - 在 VLM 输入中追加可学习的 **潜在查询 token**（`Nq=8`）；
  - 通过**专家感知注意力掩码（expert-aware attention mask）**防止动作专家直接 attend 查询 token，保证查询 token 仅通过潜在动作预测和后续条件化模块影响专家；
  - 查询隐藏状态经轻量投影头映射到 OAT 潜在空间：`ẑ = Wz LN(h_q)`；
  - 用 Smooth-L1 损失对预测潜在动作和 OAT 编码的目标潜在动作进行对齐（`L_align`，式 6）。
- **上下文门控动作条件化（Context-Gated Action Conditioning）**：
  - 训练时使用 OAT 编码的真实潜在动作作为条件来源，推理时替换为 VLM 预测的潜在动作（式 7）；
  - 条件 token 经线性投影为专家兼容的 conditioning tokens；
  - 动作专家每层在 self-attention 之后、FFN 之前，用归一化后的动作隐藏状态对条件 token 做 **cross-attention** 检索潜在动作更新 `u_l`（式 9）；
  - 计算**上下文门** `g_l = σ(Wg tanh(Wx s_lx + Wu s_lu))`（式 11），其中门值由当前动作状态和检索到的潜在更新共同决定，为**通道级、跨动作 token 共享**；
  - 通过**门控残差连接**注入更新：`x_l += g_l ⊙ u_l`（式 12），将"检索"与"注入"分离，相比固定融合更好地保留专家连续动作建模能力。
- **训练与推理**：
  - 总损失 `L = L_act + λ_align L_align`（式 13），`λ_align=0.1`；
  - 训练时 OAT 冻结，既作为对齐目标也作为专家条件来源；推理时移除 OAT，专家仅依赖 VLM 预测的潜在动作——**训练时利用未来动作结构作为监督，部署时保持 VLM 原生**。

## 6. 论文的主要结论与发现

- CAC-VLA 在 **LIBERO 上达到 98.3% 平均成功率**（强项为 Object 和 Goal 套件），在 **LIBERO-Plus SFT 设置下达到 89.5%**，均优于大部分现有方法，且大幅超越其基础架构 π0.5 的复现结果。
- 潜在动作时域长度 `Hl=20` 在 LIBERO 上效果最佳，说明**适度的未来动作上下文**最有利于当前动作块的生成。
- 消融显示：去掉潜在动作条件化使平均成功率从 98.3% 降到 98.0%，再去掉上下文门进一步降到 97.9%——潜在动作条件化和**自适应门控注入均优于固定融合**。
- 上下文门的可视化分析表明：门值随 flow step、任务套件和任务阶段动态变化，说明模型确实学到了**任务相位和生成状态自适应的条件化强度**，而非固定强度的残差注入。
- 真实世界实验中，CAC-VLA 在 pick-and-place 上 Task Score 达 72%、Full SR 达 64%，明显优于 π0.5（48%/16%）；block stacking 的 Stacking SR 为 52% vs 36%。
- 总体结论：上下文门控的潜在动作条件化是一种**有效的 VLM-动作专家接口**，无需额外动作生成框架即可提供动作级引导。

## 7. 优点

- **接口设计新颖轻量**：在 VLM 内直接预测潜在动作，避免引入独立动作生成/推理模块，部署时无需 OAT 编码器，保持 VLM 原生结构。
- **训练-推理策略合理**：训练时用真实未来动作的潜在编码做监督和条件，推理时仅依赖 VLM 预测，两者通过对齐损失衔接。
- **注意力掩码设计严谨**：专家感知掩码切断查询 token 到动作专家的直接路径，确保潜在动作只能通过受控的条件化通道影响专家，便于归因。
- **上下文门控机制巧妙**：将"检索（cross-attention）"与"注入（gated residual）"分离，门值由当前动作状态和检索更新共同决定，能根据任务阶段和生成状态自适应调节引导强度。
- **实验验证较充分**：两大仿真基准 + 多组消融 + 真实世界初步验证，与主流方法（尤其 ACoT-VLA）的对比有说服力；补充材料提供了门行为的深入分析（flow step、任务套件、阶段级热力图）。
- **报告了详细超参数**：模型配置、训练超参数、优化细节均有明确记录，可复现性较好。

## 8. 不足与局限

- **作者自述局限**：真实世界评估仅覆盖单一桌面抓取-放置/堆叠任务、一种机器人本体（UR7e）、少量演示；潜在动作预测不准确或固定潜在动作时域长度与当前任务阶段不匹配时仍可能失败，尤其长时域或更多样化操作场景。

## 摘要
基于大型预训练模型的视觉导航策略迄今为止遵循一个常见配方：专用视觉编码器、定制动作头，以及在数千小时跨具身数据集上的训练。我们质疑这一配方是否必要。本文提出GemNav，一种视觉机器人导航策略，它仅对语言塔进行低秩适配（LoRA），冻结多模态大语言模型（MLLM），用于短到中等范围的路点导航，无需辅助视觉编码器，也无需连续回归头。路点和分类导航信号共享由语言模型头生成的单一离散标记词汇表，软解码辅助损失恢复了纯交叉熵训练所丢弃的度量结构。在单个8.7小时开放语料上（比竞争性训练集小约三个数量级），该策略零样本迁移到四个物理上不同的未见环境，并在20次真实世界试验中（包括开放停车场、有障碍物停车场、长距离户外化工园区和室内仓库）在距目标0.25-0.42米内停止。基于短图像历史的条件化改善了离线指标，但对机器人没有实际收益，这表明一旦预训练视觉特征到位，时间上下文所能带来的增益存在上限。这些结果表明，冻结MLLM的离散标记适配可为基础模型机器人导航提供一种数据高效、可部署的替代方案。

## Abstract
Visual navigation policies built on large pretrained models have so far followed a common recipe: a dedicated visual encoder, a bespoke action head, and training on thousands of hours of cross-embodiment datasets. We ask whether this recipe is necessary. In this paper, we introduce GemNav, a visual robot navigation policy that adapts a frozen Multimodal Large Language Model (MLLM) for short-to-medium horizon waypoint navigation using Low-Rank Adaptation (LoRA) on the language tower alone, with no auxiliary visual encoder and no continuous regression head. Waypoints and categorical navigation signals share a single discrete token vocabulary generated by the language-model head, and a soft-decoded auxiliary loss recovers the metric structure that pure cross-entropy training discards. On a single 8.7-hour open corpus, roughly three orders of magnitude smaller than competing training sets, the policy transfers zero-shot to four physically distinct unseen environments and stops within 0.25-0.42m of the goal across 20 real-world trials covering an open carpark, an obstacle carpark, a long outdoor chemical yard, and an indoor warehouse. Conditioning on short image histories improves offline metrics but yields no robot benefit, pointing to a ceiling on what temporal context adds once pretrained vision features are in place. These results indicate that discrete-token adaptation of frozen MLLMs can provide a data-efficient, deployable alternative for foundation model robot navigation.

# 2. 方法论

## 2.1 核心思想

- 将视觉导航建模为**条件序列预测**：给定当前相机视图（以及可选历史帧）、目标规格（目标图像和/或 2D 目标坐标），让模型使用**语言模型原生 token 接口**输出离散化的路点序列或停止信号。
- 不设置连续回归头，也不训练或附加视觉编码器；仅对 LLM 语言塔的线性层施加 LoRA，视觉塔完全冻结。

## 2.2 关键技术细节

- **离散值 token 化**：
  - 从 Gemma-4 的保留 `<unusedN>` token 中分配 69 个槽位：64 个值 bin token + 5 个角色 token（`<bot traj>`、`<eot traj>`、`<goal reached>`、`<goal coord>`、`<goal unreachable>`）。
  - 每个路点坐标轴（x 或 y）均匀量化到 K=64 个 bin，范围 [−B, B]，B=15 m；每个 bin 宽 0.469 m，半 bin 重构误差 0.234 m。
- **目标序列格式**：
  - 轨迹样本：`<bot_traj>` + 16 个值 token（8 个路点 × x/y）+ `<eot_traj>`，共 18 token。
  - 停止样本：`<bot_traj>` + `<goal_reached>`/`<goal_unreachable>` + `<eot_traj>`，统一为 3-token 序列。
  - 目标坐标编码使用与输出相同的值 bin token，并以 `<goal coord>` 前缀，避免“条件表示”和“生成表示”之间的鸿沟，从而支持零样本的 pose+image 联合导航。
- **训练损失**：
  - 主损失为 token 级交叉熵 \(L_{CE}\)（prompt 位置 mask 为 −100）。
  - 辅助“软解码回归损失” \(L_{aux}\)：将值 bin logits 做 softmax 后与 bin 中心加权求和，得到软解码预测 \(\hat{a}_k\)，再与真实坐标计算 MSE，仅对轨迹样本有效，权重 \(\lambda_{aux}=0.1\)。
  - 该辅助损失恢复了纯交叉熵丢弃的**度量/序数结构**，在 ego-only 验证集上将 ADE 从 1.05 m 降至 0.81 m（降低 23%）。
- **LoRA 配置**：作用于语言塔全部 7 类线性层（q/k/v/o/gate/up/down），r=32，α=16，dropout=0；视觉塔无任何参数更新。

## 2.3 数据处理与采样

- 训练数据仅用 SCAND 的图像与位姿流（约 8.7 小时）。
- **目标采样器**：采用基于弧长的距离采样——均匀抽取目标弧长 \(d \sim \text{Uniform}(0.5, 14)\) m，沿轨迹推进直到位移超过 d，得到目标帧。该采样器覆盖了部署相关的全部距离范围，而非固定帧偏移。
- 后置过滤器：剔除目标在机器人后方（\(x_g < -0.3\) m）以及需要原地旋转（yaw 差 > 30°）的样本；左右翻转增强扩展语料；约 10% 的图像目标样本替换为不同轨迹的帧并输出 `<goal unreachable>`，训练“拒绝规划”能力。

# 6. 主要结论与发现

- **冻结视觉塔足够**：不训练视觉编码器、不加辅助视觉编码器，GemNav 在 4 个未见环境中的全部 20 次 pose-goal 试验均成功（5/0/0），最终距目标 0.25–0.42 m。
- **离散 token 动作表示可行**：通过 64-bin 值 token 与停止/不可达 token 的统一序列，MLLM 可以输出连续路点并自主停止。
- **辅助软解码损失有效**：比纯交叉熵降低 23% 验证 ADE，且不影响离散停止信号。
- **数据效率显著**：仅 8.7 小时 SCAND 数据（约为 OmniVLA 训练集的 1/1000），即可获得可部署的策略。
- **离线指标与真机行为可能脱节**：历史上下文（h=2/4）在 OOD 验证集上 ADE 单调改善，但真机反而变慢甚至成功率下降；帧对齐采样在 in-dist ADE 更好，但 OOD pose FDE 高达 2.88 m 且真机完全失败。这说明 in-dist ADE 不能单独作为部署能力的指示器。
- **OmniVLA 在复杂场景下缺乏目标锚定**：在障碍物环境中，OmniVLA 会丢失目标方向，而 GemNav 能持续闭环于目标坐标。

# 7. 优点

- **极高数据效率**：用单个 8.7 小时公开语料替代数千小时跨具身数据，且无需仿真或人工采集。
- **架构简洁、模块解耦**：冻结整个 MLLM（含视觉塔），仅训练 LoRA 适配器；无专用视觉编码器、无附加动作头，统一使用语言模型原生 token 接口。
- **动作表示设计有创造性**：离散值 bin + 软解码回归损失在保持离散接口的同时恢复度量结构，是一种新颖且可复用的训练技巧。
- **对负结果的诚实报告**：明确报告“历史上下文有离线收益但无真机收益”的负结果，并给出时间滞后效应的解释，有助于社区理解。
- **真实部署验证扎实**：覆盖 4 个跨场景环境（开放/障碍/户外长距/室内），且与人类专家和 SOTA 基线对照。

# 8. 不足与局限

- **单一平台与单一训练数据**：仅在 Spot 上训练和部署，未做跨机器人本体迁移验证，泛化性结论仍有限。
- **纯图像目标停止不可靠**：ego-only 模态在 Carpark 中仅 1/5 自动停止；当前策略依赖 2D 目标坐标，限制了无定位信息的应用场景。
- **动作空间受限**：2D (x,y) 路点无法表达原地旋转，且会过滤机器人后方的目标（需要 U-turn 的场景无法处理）。
- **历史上下文的结论存在 confound 风险**：真机测试的 h=2/h=4 检查点来自独立的四阶段链，且离线指标与在线行为脱节的解释（时间滞后轨迹效应）尚未完全确证。

# 9. 总结与展望

GemNav 的核心贡献在于提供了一个“反主流”的实证：在路点导航任务上，冻结视觉塔、仅用 8.7 小时单机器人数据、只训练语言塔 LoRA 的极简方案，可以在未见过的多样化物理环境中取得稳健的零样本性能。这一结果将研究者的注意力从“更大的视觉编码器”重新导向“动作表示设计”和“数据采样策略”，为数据稀缺的真实场景提供了一条低成本落地路径。

未来可能的方向包括：将 2D 路点扩展为 6-DoF 动作以支持原地旋转与复杂操作；引入定位漂移鲁棒的目标表示；将距离采样与课程学习结合以覆盖更长轨迹；以及在多机器人本体上验证该范式的跨具身泛化能力。同时，论文中“离线指标与真机行为脱节”的负结果也提示，导航策略评估需要更重视在线部署验证，而非仅依赖传统 OD 指标。

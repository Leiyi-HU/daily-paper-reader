## 摘要
语言条件化操作需要既精确的接触丰富控制，又需要对语言、场景和长时程进行稳健推理。端到端的视觉-语言-动作（VLA）模型提供了强大的局部视觉运动技能，但它们是在分布内的任务轨迹上训练的，并且经常在诸如语义重定向、目标重新绑定、空间布局变化和不稳定局部接触等部署扰动下失败。LLM编码智能体提供了互补的语义和组合推理，但纯粹的分析性原语在应对不规则抓取、受限放置和铰接物体交互时存在困难。我们提出了Harness VLA，一个记忆增强的智能体框架，它将冻结的VLA暴露为可重试的接触丰富原语，并将其与一个固定的小型分析性原语库组合，用于接地、分阶段、运输、导航和释放。该框架不是扩展技能库，而是从任务特定的执行轨迹、全局成功规则和失败模型中学习这些固定原语的操作范围。通过将语义重新接地、非接触执行和VLA重新分阶段提升到规划器，同时保留冻结的VLA用于局部接触丰富阶段，Harness VLA无需微调即可将预训练的VLA扩展到其原始轨迹分布之外。在受扰动的桌面、家庭厨房以及从干净到随机的双臂操作中，Harness VLA在LIBERO-Pro和RoboCasa365上分别比最强相关基线提高了38.6和25.4个百分点，并在RoboTwin C2R上达到58.4%。

## Abstract
Language-conditioned manipulation requires both precise contact-rich control and robust reasoning over language, scenes, and long horizons. End-to-end Vision-Language-Action (VLA) models provide strong local visuomotor skills, but they are trained on in-distribution task trajectories and often fail under deployment perturbations such as semantic retargeting, goal re-binding, spatial-layout shifts, and unstable local contacts. LLM coding agents provide complementary semantic and compositional reasoning, but purely analytic primitives struggle with irregular grasping, constrained placement, and articulated-object interaction. We present Harness VLA, a memory-augmented agentic framework that exposes a frozen VLA as a retryable contact-rich primitive and composes it with a small fixed library of analytic primitives for grounding, staging, transport, navigation, and release. Rather than expanding the skill library, the harness learns the operating range of these fixed primitives from task-specific execution traces, global success rules, and failure models. By lifting semantic re-grounding, non-contact execution, and VLA re-staging to the planner while reserving the frozen VLA for local contact-rich phases, Harness VLA extends pretrained VLAs beyond their original trajectory distribution without finetuning. Across perturbed tabletop, household kitchen, and clean-to-randomized bimanual manipulation, Harness VLA improves over the strongest relevant baselines by 38.6 and 25.4 percentage points on LIBERO-Pro and RoboCasa365, respectively, and reaches 58.4% on RoboTwin C2R.

- **核心问题**：语言条件化机器人操作要求同时具备精细的接触类控制能力和对自然语言、场景及长时程任务的推理能力。现有的端到端视觉-语言-动作（VLA）模型虽然擅长局部的接触类操作（如抓取、插入、按按钮），但其训练数据来自分布内任务轨迹，在部署时面对语义重定向（instruction redirection）、目标重新绑定（goal re-binding）、空间布局变化（position swap）以及不稳定的局部接触时，性能会急剧下降，甚至重复训练时的行为而忽略新指令。
- **补足方案的问题**：基于 LLM 的编码智能体（coding agents）虽然具备互补的语义组合推理能力，但它们依赖的分析式原语（如运动学规划、抓取释放）难以处理不规则抓取、受限放置和铰接物体交互等精细接触任务。
- **论文的整体含义**：与其继续微调更强的 VLA 或不断扩大技能库，不如采取“非对称分层”思路——将预训练 VLA 冻结，作为一个可重试的接触类原语；将语义接地、非接触执行、运输、导航、重试调度等任务交给高层规划智能体；并通过记忆模块学习这些固定原语的有效工作范围。该框架无需微调 VLA，即可将其扩展到原始轨迹分布之外的操作场景。

### 2. 方法论：核心思想、关键技术细节与算法流程

- **核心思想**：构建一个“记忆增强的智能体框架”（Harness VLA），使 LLM 规划器在固定且小型的原语库上进行组合调度：
  - 冻结的 VLA 通过统一原语接口 `VLA_ACT` 暴露为局部接触操作原语；
  - 固定分析原语用于目标接地、自由空间运输、姿态调整、导航、释放、失败后的重新布置等非接触结构；
  - 原语库在部署阶段固定不变，不允许规划器发明新原语。
- **智能体执行循环**：
  1. 规划器接收当前 RGB-D 观测、机器人状态、任务描述、检索到的任务特定记忆和全局记忆；
  2. 规划器输出一个结构化的 JSON 原语调用；
  3. 环境执行该原语，直到内部后置条件满足；
  4. 返回新的观测，规划器再次决策；
  5. 循环直到任务谓词满足或步骤预算耗尽。
- **关键机制：记忆系统**
  - **任务特定记忆（Task Specific Memory）**：在单个参考 seed 上探索出成功的原语调用轨迹，以参数化 JSONL 形式保存（将具体空间坐标替换为符号感知查询），跨空间布局重用；
  - **全局记忆（Global Memory）**：聚合跨任务的成功规则（如 VLA 使用时机）和失败模型（如空抓、假成功、错误目标选择）；
  - 记忆在探索过程中逐步迭代构建，而非一次性写入。
- **两阶段生命周期**：
  - **探索引导阶段**：允许使用 `RESET` 原语和充裕时长，在单个参考场景中反复尝试获得成功轨迹并写入记忆；
  - **部署评估阶段**：禁用 `RESET`，缩短预算，规划器检索记忆并基于当前观测动态重接地点执行。
- **原语库设计**：包括分析复合原语（`MOVE_TO`、`MOVE_POSE`、`NAVIGATE_TO`）、分析原子原语（`ROTATE_WRIST`、`ROTATE_PITCH`、`SET_GRIPPER`、`RELEASE`、`MOVE_BASE`）以及 VLA 原语 `VLA_ACT`。`VLA_ACT` 由规划器给定提示和提前返回谓词，冻结的 VLA 以小段动作块方式执行接触交互。
- **文件中介的 REPL 协议**：规划器通过 JSON 文件与模拟器交互，不能访问物体真实位姿等特权信息；所有感知基础来自 RGB、深度和世界地图。

### 6. 主要结论与发现

- **无微调扩展 VLA 能力**：通过将冻结 VLA 作为接触原语、由规划器负责语义接地与非接触结构，可将模型扩展到其训练轨迹分布外的扰动场景，且无需微调或部署时扩充原语库。
- **性能大幅提升**：
  - LIBERO-Pro 上 Harness VLA（CC）在 82.4%，比 RATS 的 43.8% 提升 38.6 个百分点；而直接使用同一冻结基座 πRLinf 只有 50.0%，说明增益来自框架而非 VLA 本身；
  - RoboCasa365 上 Harness VLA（Codex）55.4% vs RLDX-1 30.0%，提升 25.4 个百分点；
  - RoboTwin C2R 达到 58.4%（CC），优于直接后端 LingBot-VLA 的 50.4%。
- **标准性能保持**：标准 LIBERO 上 Harness VLA（CC）96.0%，与冻结 πRLinf 的 95.3% 基本相当，在某些套件（如 OBJECT 100%）甚至更优。
- **机制归纳**：
  1. 规划器级语义重接地恢复了任务条件行为；
  2. 规划器分阶段调用/重试 VLA 提升了冻结策略的可靠性与可恢复性；
  3. 分析原语隔离了非接触执行，使 VLA 只负责局部接触交互。
- **记忆的作用**：任务特定记忆对空间位置交换场景至关重要（Goal-S 从零样本 31.0% 提升到少样本 87.0%），而指令重定向更多依赖在线规划器推理。

### 7. 优点

- **无需微调**：直接复用开源或已有冻结 VLA，降低了算力成本，并便于即插即用；
- **固定原语库的设计非常简洁**：不随任务扩展技能库，而是通过记忆和学习让智能体掌握现有原语的工作范围，提高了可解释性和可控性；
- **记忆系统设计精巧**：任务特定记忆（参数化轨迹）与全局记忆（成功规则/失败模型）分离，具备少样本重接地能力和跨任务复用能力；
- **具备可审计性**：文件介导的 REPL 记录了每一步原语调用与状态，方便调试和追踪失败原因；
- **实验设计较好**：在多个标准 benchmark 基础上引入扰动和零样本设置，并配有机制分析、原语使用统计、VLA 调用次数消融，从多角度对增益来源进行了验证；
- **框架通用性较强**：同一统一原语接口可适应单臂桌面、移动厨房和双臂操作，VLA 后端可灵活替换。

### 8. 不足与局限

- **开放反馈回路**：高层规划器与低层 VLA 之间缺乏紧密的奖赏/可微反馈信号，VLA 内部失败不能被端到端优化；
- **缺少联合微调与偏好学习**：作者承认未能利用环境奖励和人类偏好进行强化学习（如 GRPO），这限制了在更复杂任务上的进一步提升；
- **细粒度感知不足**：缺少细粒度图像描述能力，在杂乱场景和超长时程任务中的结构推理仍受限；
- **依赖外部 LLM 规划器**：使用 Codex / Claude Code 作为规划器，未充分报告 LLM 推理成本、延迟及其不稳定因素；
- **场景局限**：所有实验均在 MuJoCo/Robosuite 等仿真环境中完成，缺乏真实机器人部署验证；
- **未见组合任务仍弱**：RoboCasa365 的 Composite-Unseen 上成功率仅约 15%，说明未见过任务模板的组合推断仍是短板；
- **零样本空间位置交换性能显著下降**：Goal-S 零样本仅 31.0%，说明任务特定记忆对空间重排的泛化必不可少，而在线推理在纯几何变化下能力有限；

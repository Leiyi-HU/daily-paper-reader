## 摘要
视觉-语言-动作（VLA）模型旨在将多模态输入映射到机器人动作。然而，大多数现有方法难以覆盖复杂的动态场景，因为它们将所有视觉标记统一处理，并依据人工选择的因素进行推理，缺乏强调任务关键证据的机制，且忽略了潜在因素。为解决这一问题，我们提出了LEEVLA，一种用于在潜在环境演化中关注关键信息的VLA架构，它显式地引导模型关注信息丰富的区域，同时保留潜在世界表示的结构化演化。为了识别显著且与指令相关的区域，我们引入了漂移引导的动态优先级化（DGDP），它结合了动态位置优先级化（DPP）和语义漂移引导（SDG），在训练期间指导VLA智能体关注何处。在此基础上，我们引入了结构化特征流生成（SFFG），通过原型到外围（P2P）预测来模拟这些优先特征在潜在空间中应如何演化，并采用互邻域对比（MC）损失来维护邻域间的拓扑一致性。DGDP和SFFG共同构成了一个任务感知的“何处-如何”训练框架。在VLA基准上的大量实验表明，LEEVLA始终优于先前方法，证实了显式任务证据引导和结构化潜在推理对于可扩展的VLA都至关重要。我们的代码可在 https://github.com/LyuQi127/LEEVLA 获取。

## Abstract
Vision-language-action (VLA) models aim to map multimodal inputs to robot actions. However, most existing approaches struggle to cover complex dynamic scenarios due to treating all visual tokens uniformly and reasoning with human-selected factors, which lack mechanisms to emphasize task-critical evidence and ignore underlying factors. To address this issue, we propose LEEVLA, a VLA architecture for seeing what matters in Latent Environment Evolution that explicitly guides the model toward informative regions while preserving the structured evolution of latent world representations. To identify salient and instruction-relevant regions, we introduce drift-guided dynamic prioritization (DGDP), which combines dynamic position prioritization (DPP) with semantic drift guidance (SDG) to guide the VLA agent where to attend during training. On top of this, we introduce structured feature flow generation (SFFG), which models how these prioritized features should evolve in latent space via prototype-to-periphery (P2P) prediction, and a mutual-neighborhood contrastive (MC) loss to maintain topological consistency among neighborhoods. Together, DGDP and SFFG form a task-aware "where-how" training framework. Extensive experiments on VLA benchmarks show that LEEVLA consistently outperforms prior methods, confirming that explicit task-evidence guidance and structured latent reasoning are both crucial for scalable VLA. Our code is available at https://github.com/LyuQi127/LEEVLA.

## 1. 核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型旨在将多模态观测（视觉、本体感觉、语言指令）直接映射为机器人底层控制动作，是实现开放环境具身智能的关键路径。
- **存在的问题**：
  - **对所有视觉 token 一视同仁**：现有 VLA 方法在训练中均匀处理所有图像 patch，导致梯度被静态背景和与任务无关的区域稀释，难以聚焦任务关键证据。
  - **依赖人工选择的外部线索**：一些方法（如 CoT-VLA、DreamVLA）依赖分割掩码、深度图、子目标图像等人类指定的上下文线索作为显式推理中间步骤，引入了额外计算开销，且受限于辅助模型性能。
  - **已知因素与未知因素失衡**：根据因果图（图1a），动作由已知（可人工标注）和未知（潜在但任务相关）因素共同决定。过度依赖人工选择的已知因素会缩小模型在潜在空间中的搜索范围，使其难以发现未被标注但关键的因素，导致同一物体跨模态变化或不同物体同模态相似时表现脆弱。
- **核心洞察**：应直接在**潜在特征空间**中推理，利用预训练视觉骨干（如 DINOv2、SigLIP）已编码的语义、外观、几何等多模态纠缠信息，将动作视为驱动环境状态在高层表示上演化的"驱动器"。同时，必须显式引导模型**"关注哪里"（where to attend）**并建模**"如何演化"（how to evolve）**。

## 2. 方法论

### 2.1 总体框架

- 提出 **LEEVLA**（Latent Environment Evolution VLA）架构，由两大模块构成：
  - **DGDP**（Drift-Guided Dynamic Prioritization，漂移引导动态优先化）——解决"where"：自动发现显著且与指令相关的区域。
  - **SFFG**（Structured Feature Flow Generation，结构化特征流生成）——解决"how"：建模优先特征在潜在空间中的结构化演化。
- 两个模块**仅在训练阶段生效，推理阶段零额外开销**（表4验证）。

### 2.2 DGDP：漂移引导动态优先化

由两部分组成：

**动态位置优先（DPP，Dynamic Position Prioritization）**
- 量化每个 patch 的时序动态性：计算相邻时间步特征间的余弦相似度变化
  \[
  \theta_i = 1 - \cos(v_{t,i}, v_{t+T,i})
  \]
- 动态分数高的区域（物体交互点、手臂运动区域）获得更高预测损失权重。

**语义漂移引导（SDG，Semantic Drift Guidance）**
- 先计算每个 patch 与语言指令的语义相关分数：
  \[
  r_{t,i} = \max_{1 \le j \le M} \langle \tilde{x}_{t,i}, \tilde{c}_j \rangle
  \]
- 定义指令相关语义漂移：
  \[
  \Delta_i = \text{clip}((r_{t+T,i} - r_{t,i})/\tau, -\delta, \delta)
  \]
- 归一化后得到语义漂移引导因子 \(\omega_i = \exp(\tilde{\Delta}_i/\tau)\)，最终优先权重：
  \[
  \beta_i = \sigma(\omega_i \cdot \theta_i)
  \]
- 效果：既关注动态区域，又确保语义向指令相关方向漂移的区域被放大，抑制语义漂移向背景/无关语义的区域（可视化见图3b）。

### 2.3 SFFG：结构化特征流生成

由两部分组成：

**原型到外围预测（P2P，Prototype-to-Periphery）**
- 对多视角未来特征拼接结果做联合聚类：\(C = \mathcal{F}([f_{p,t+T}; f_{w,t+T}]) = \{c_\ell\}_{\ell=1}^L\)，得到各簇质心 \(\mu_\ell\)。
- 对每个簇内成员按到质心的欧氏距离排序（近→远，即原型→外围），形成有序序列。
- P2P 预测损失：
  \[
  L_{\text{P2P}} = \frac{1}{|C|} \sum_{\ell=1}^{|C|} \frac{1}{|\vec{c}_\ell|} \sum_{j \in \vec{c}_\ell} (\alpha + \beta_j) \cdot \varphi(\hat{v}_{t+T,j}, v_{t+T,j})
  \]
  - \(\varphi(\cdot)\) 为余弦嵌入损失，\(\alpha\) 为全局调制因子（保持全局布局感知），\(\beta_j\) 为 DGDP 权重。
- 意义：扁平化 token 预测会打乱特征空间的局部语义结构，P2P 通过簇内有序预测保持空间语义连续性。

**互邻域对比损失（MC，Mutual-neighborhood Contrastive）**
- 针对聚类噪声导致的非对称/虚假邻接关系，构建高置信度对比对：
  - 一阶邻居集 \(G_i^{(1)}\)：与 anchor i 最相似的 K（=10）个 token；
  - 二阶邻居集 \(G_i^{(2)}\)：每个一阶邻居各自的 M（=5）个最近邻居的并集；
  - 正样本集仅保留**互邻**（mutual）token：\(G_i^+ = \{j | j \in G_i^{(1)} \cup G_i^{(2)},\ i \in G_j^{(1)} \cup G_j^{(2)}\}\)。
- 使用 InfoNCE 损失拉近互邻 token，保持局部拓扑一致性。

### 2.4 训练目标

\[
L_{\text{total}} = \lambda_1 L_{\text{action}} + \lambda_2 L_{\text{P2P}} + \lambda_3 L_{\text{MC}}
\]

- \(L_{\text{action}}\)：L1 动作回归损失（并行动作解码，对演示噪声鲁棒）。
- 采用"where–how"联合训练框架，未来特征解码器仅作为动作策略的辅助训练监督。

## 7. 局限性与未来方向

- **对预训练视觉骨干的依赖**：方法假设 DINOv2/SigLIP 等骨干已编码足够丰富的语义与几何特征；若骨干对特定任务场景适应不足，语义漂移和动态优先化的可靠性可能下降。
- **训练计算开销**：MC 损失在一次训练迭代中耗时约 1.2s（表4），在多模态大模型训练中成本较高，需要进一步优化采样或近似邻近搜索策略。
- **真实世界评测规模有限**：仅在一台 UR5 上进行 3 类任务共 60 次试验，缺少多机器人平台和更复杂灵巧操作的验证。
- **聚类与互邻域的超参数敏感**：K、M 及阈值 δ 等需针对不同任务调优，通用性有待增强。
- **未来工作**：可将该机制扩展到跨本体（人形/机械臂）、跨任务（多语言指令）的持续学习场景；探索自适应聚类数量和动态阈值；进一步降低训练开销并开放源码。

## 8. 总体评价

LEEVLA 通过"动态优先化 + 结构化特征流"双模块，直接在潜在特征空间引导模型关注关键区域并建模特征演化，有效避免了对外部人工线索的依赖，同时在 LIBERO、CALVIN 和真实机器人上取得了领先性能。其理论动机清晰，实验设计较全面，尤其在零额外推理开销这一点上具有很强的实用性。主要不足在于真实场景规模偏小、训练效率有待提升，以及部分超参数对任务分布可能存在敏感性。整体而言，该方法为 VLA 模型的训练范式提供了一种有价值的新思路。

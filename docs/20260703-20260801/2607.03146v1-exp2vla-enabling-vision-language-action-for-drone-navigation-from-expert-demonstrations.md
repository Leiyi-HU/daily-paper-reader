## 摘要
视觉-语言-动作（VLA）模型通过在一个端到端框架中直接连接感知、语言和动作，为直观的机器人控制开辟了新路径。然而，对于无人机而言，实际应用仍然困难，因为现有解决方案要么计算量大，要么在复杂环境中能力不足。在这项工作中，我们提出了一种实用的专家蒸馏流程（Exp2VLA），用于语言条件下的无人机导航。核心思想是将从强化学习、遥操作或其他控制器获得的专家行为蒸馏为可用于微调紧凑型VLA模型的训练数据。这使得现有控制策略能够被迁移到统一的语言引导导航模型中，减少了手动系统集成，并降低了部署新机器人行为的门槛。在跨多物体场景的模拟到模拟和仿真在环实验中，微调后的模型能够处理各种语义命令，并泛化到未见过的目标组合。所提出的框架展示了专家策略蒸馏如何帮助机电一体化系统从专用控制模块转向更灵活、可复用的机器人智能。

## Abstract
Vision-language-action (VLA) models open a new path toward intuitive robot control by directly linking perception, language, and action in a single end-to-end framework. Yet for UAVs, practical adoption remains difficult because existing solutions are either computationally heavy or insufficiently capable in complex environments. In this work, we propose a practical expert-distillation pipeline (Exp2VLA) for language-conditioned drone navigation. The core idea is to distill expert behavior, obtained from reinforcement learning, teleoperation, or other controllers, into training data that can be used to fine-tune compact VLA models. This allows existing control strategies to be transferred into a unified language-guided navigation model, reducing manual system integration and lowering the barrier for deploying new robot behaviors. Experiments in both sim-to-sim and simulation-in-the-loop settings across multi-object scenes show that the fine-tuned models can handle varied semantic commands and generalize to unseen target compositions. The proposed framework demonstrates how expert-policy distillation can help mechatronic systems move from specialized control modules toward more flexible and reusable robot intelligence.

**整体含义：**
论文提出 Exp2VLA 专家蒸馏管线，将已有的成熟控制策略（强化学习、遥操作、经典控制等）自动转换为可用于微调紧凑 VLA 模型的训练数据，从而把专用控制模块迁移为统一的、语言引导的端到端导航模型。该方法降低了手动系统集成成本和新行为部署门槛，推进无人机控制从专用模块走向更灵活、可复用的机器人智能。

## 2. 方法论

**核心思想：专家策略蒸馏（Expert Distillation）**
- 训练一个"专家策略"作为行为来源，将其决策过程记录为多模态演示数据，再通过模仿学习微调 VLA 模型，使 VLA 模型在推理时复现专家行为。

**关键技术细节：**

1. **专家数据收集**
   - 使用 PPO 算法（RLGames 框架，Isaac Lab 仿真环境）训练连续控制导航策略作为 oracle 专家。
   - 专家策略接收显式空间目标坐标，引导无人机飞向视觉目标（目标偏移 0.5m 设置在物体前方）。
   - 每一步记录四类信息：
     - RGB 第一人称图像（640×480）
     - 6 维无人机状态向量（机体坐标系线速度与角速度）
     - 3 维连续速度动作（前向速度 \(v_x\)、垂直速度 \(v_z\)、偏航角速度 \(\dot{\psi}\)）
     - 自然语言指令（如 "Fly to the red cube"）
   - 原始数据转换为 **LeRobot 数据集格式** 以兼容标准 VLA 微调流程。

2. **VLA 模型微调**
   - 微调两个模型：**π0.5**（4B 参数：PaliGemma 3B + Flow Matching 动作专家 300M）和 **SmolVLA**（0.45B 参数）。
   - 单块 NVIDIA RTX 4080 Super（16GB）上以 BF16 精度训练，启用梯度检查点。
   - **冻结视觉编码器**（π0.5 的 SigLIP 为 400M 参数），仅更新动作预测模块（"expert-only"训练），保留骨干网络的语义知识同时专注控制能力。
   - 训练配置：60,000 步迭代；π0.5 batch size 16，SmolVLA batch size 64；学习率 5×10⁻⁴，余弦衰减。

3. **闭环推理**
   - 语言指令在启始时一次性 tokenize，每次推理调用使用最新第一人称图像、归一化状态和固定语言 token。
   - 采用**多动作分块（multi-action chunking）**：策略一次预测 K=50 个动作（\(v_x, v_z, \dot{\psi}\)），依次执行，减少推理频率以保障实时性。
   - 成功条件（Algorithm 1，公式 1）：
     \[
     S = 1\left[\min_{t} \|p_t - g\|_2 \le \epsilon\right]
     \]
     其中 \(\epsilon = 0.60\) m。

## 6. 主要结论与发现

1. **4B 级 VLA 适合无人机导航**：Exp2VLA(π0.5) 在多物体训练配置下平均成功率 65%，零样本颜色置换下仍有 51.7%，证明了中规模 VLA 处理语义导航任务的可行性。
2. **视觉编码器容量是关键瓶颈**：极紧凑的 SmolVLA 在多物体环境中成功率骤降至 15%，表明视觉编码器容量不足时难以区分多个不同颜色/形状的物体。
3. **组合式泛化存在但不完全**：π0.5 能泛化到未见的颜色-形状组合，但可靠性低于训练配置（65%→51.7%），且蓝锥表现明显偏弱（29%），说明组合泛化并不均匀。
4. **不偏向单一物体**：三种目标（红立方、蓝圆柱、绿锥）成功率较为一致（62.6%~68.0%），说明多任务语言指令训练有效，未过拟合单一目标类型。
5. **算力权衡主要在内存而非速度**：SmolVLA 相比 π0.5 内存节约近半，但延迟仅降低约 12%，因此选择大模型不会显著牺牲实时性。
6. **SITL 可行**：证明了 off-board VLA 推理 → ROS2 传输 → 真实无人机执行的闭环流程在技术上可工作。

## 7. 优点

- **方法通用性强**：对齐了"任何专家策略 → VLA 数据 → 语言导航模型"的通用范式，可扩展至遥操作、经典控制等其他来源。
- **训练门槛低**：单张 16GB 消费级 GPU + 冻结视觉编码器 + BF16 + 梯度检查点，大幅降低了 VLA 微调硬件需求。

- **数据开放**：完整数据集公开，保障结果可复现，促进后续研究。
- **实验设计有区分度**：通过单物体→多物体→颜色置换三层评测，系统性地揭示了不同规模模型的能力边界。
- **落地意识强**：SITL 演示证明从仿真训练到真实平台的部署路径存在，不是停留在纯仿真阶段。

## 8. 不足与局限

- **纯仿真验证**：所有定量结果均来自 Isaac Lab 仿真，未包含真实环境的定量成功率，存在 sim-to-real gap 风险。
- **SITL 不够完整**：真实飞行只是概念验证，VLA 推理在外部工作站而非机载运行，实时性与可靠性均未量化。
- **缺乏对比与消融**：没有与大型 VLA（7B 类）或其他导航策略比较，没有消融实验，因果关系证据不足（如 SmolVLA 的低性能是编码器问题还是整个模型容量问题的论证不充分）。
- **语言规模有限**：仅 3 条指令、3 种物体、3 种颜色，未涵盖复杂指令（如带空间关系、否定、多物体顺序导航）和视觉扰动（光照、遮挡、动态障碍物）。
- **零样本测试偏弱**：仅做颜色置换（同三种物体重新排列），未评估全新类别、全新场景或

- 未评估全新类别、全新场景或更复杂的空间推理（如“绕过红立方飞到绿锥后面”）以及具有动态障碍物或光照变化的真实视觉干扰，零样本泛化的边界远未画清。
- **状态表示依赖显式自车速度/角速度**：专家策略接收并输出连续的机体坐标系速度指令，这种设定是设计好的，但对真实飞控的底层接口、机型动力学差异较为敏感；VLA 学到的动作尺度可能难以直接迁移到不同飞控参数或机身尺寸的无人机。
- **未考虑闭环稳定性和避障行为**：实验环境中没有动态障碍物、阵风或接近地面时的地效影响；5 秒的 episode 也远短于实际任务的典型时长，实际巡检/物流任务往往需要数十秒到数分钟的持续导航，动作分块累积误差和漂移问题未得到考验。
- **缺乏多轨迹或轨迹多样性分析**：成功率只反映“是否到达”，没有评估路径质量（如偏航误差、速度平滑性、与最优路径的偏差），也没有分析失败案例的具体失效模式（卡在起始点、绕远路、还是撞上目标）。
- **专家策略本身即为数据保真度的上限**：所有训练数据都来自 PPO 专家，因此 VLA 的性能无法超越该专家；若专家策略存在系统性偏差（如只在某个速度范围内表现好），蒸馏后的 VLA 也会继承该偏差，但论文未对专家策略的单独成功率做基准测试，无法判断蒸馏损失有多大。
- **没有开源模型权重或推理代码**：虽然数据集公开，但微调后的 π0.5 和 SmolVLA 权重未开放，复现者需要自行实现完整微调流程（包括 Flow Matching 动作头等细节），降低了可复现性。

## 9. 总结与展望

Exp2VLA 在“将成熟控制专家策略蒸馏为语言引导的无人机 VLA 导航模型”这一方向上迈出了扎实的第一步。它清晰地展示了三条可行路径：以极小消费级 GPU 完成 4B 级 VLA 微调、用多动作分块解决边缘实时推理瓶颈、以及通过 off-board 推理 + ROS2 链路实现从仿真到真机的闭环。其核心贡献不在于提出全新的网络架构，而在于给出了一个**数据生成管线 + 轻量微调配方 + 语义导航评测框架**的完整组合，这对资源有限的无人机研究团队具有很高的实用参考价值。

然而，该工作距离真正的“机载自主语言导航”仍有明显距离。当前所有的定量验证都在仿真中完成，真机演示仅验证了通信链路与基本闭环可行性；视觉编码器容量与泛化能力之间的深层因果关系也尚未通过消融实验充分建立。未来的自然延伸应包括：引入多模态传感器（深度、事件相机）、覆盖更丰富的语言指令（相对位置、顺序导航、条件指令）、加入动态避障和复杂场景的真机评测，以及探索视觉编码器的轻量化蒸馏（如将 SigLIP 蒸馏到更小的学生网络）来真正压缩机载推理负担。

总体而言，Exp2VLA 是一篇方法清晰、实验完整度中等偏上、落地意识明确的论文，尤其适合作为“用 VLA 解决无人机语言导航”的 baseline 参考。

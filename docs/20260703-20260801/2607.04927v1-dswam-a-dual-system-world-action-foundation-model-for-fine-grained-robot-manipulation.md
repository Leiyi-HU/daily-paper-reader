## 摘要
世界动作模型（WAMs）通过基于视频的世界建模为机器人动作学习提供密集监督，是视觉-语言-动作（VLA）策略的一种有前景的替代方案。现有的WAM在基于物理的执行方面表现出色，但通常缺乏基于VLM的VLA中用于分解粗略指令的显式语言级规划接口。当家庭任务涉及复杂的多步目标时，这种分解变得重要，因为粗略的用户命令需要转换为一系列细粒度的可执行子任务。同时，该领域仍然缺乏对VLA和WAM执行能力的公平的真实机器人比较，因为现有系统通常在数据、机器人本体和任务协议上有所不同。为了解决分解差距以及受控WAM-VLA比较的需求，我们引入了DSWAM，一种用于精细机器人操作的双系统世界动作基础模型。DSWAM将系统1 WAM执行器作为默认控制路径，并仅在任务分解有用时可选地激活系统2视觉-语言子任务规划器。规划器从短期视觉历史和全局任务提示中预测可执行的子任务，而WAM执行器为每个指令或子任务执行世界感知的动作生成。执行器通过动作预测和视频协同训练进行训练，但推理时直接预测动作块，无需显式生成未来视频。为了使该执行路径在实际机器人上实用，我们进一步集成了TensorRT加速、异步执行和实时分块（RTC），使策略查询不会阻塞机器人控制。为了与VLA策略进行公平的真实机器人比较，我们在DeMaVLA真实世界可变形操作设置下构建和评估DSWAM，匹配机器人平台、预训练数据、后训练数据和评估标准。

## Abstract
World Action Models (WAMs) provide a promising alternative to Vision-Language-Action (VLA) policies by using video-based world modeling as dense supervision for robot action learning. Existing WAMs excel at physically grounded execution, but typically lack the explicit language-level planning interface in VLM-based VLAs for decomposing coarse instructions. Such decomposition becomes important when household tasks involve complex multi-step goals, where coarse user commands need to be converted into sequences of fine-grained executable subtasks. Meanwhile, the field still lacks a fair real-robot comparison between VLA and WAM execution capabilities, since existing systems often differ in data, robot embodiments, and task protocols. To address both the decomposition gap and the need for a controlled WAM-VLA comparison, we introduce DSWAM, a Dual-System World Action Foundation Model for fine-grained robot manipulation. DSWAM keeps a System 1 WAM executor as the default control path and optionally activates a System 2 vision-language subtask planner only when task decomposition is useful. The planner predicts executable subtasks from short-term visual history and a global task prompt, while the WAM executor performs world-aware action generation for each instruction or subtask. The executor is trained with action prediction and video co-training, but inference directly predicts action chunks without explicit future video generation. To make this execution path practical on real robots, we further integrate TensorRT acceleration, asynchronous execution, and real-time chunking (RTC) so that policy queries do not block robot control. To provide a fair real-robot comparison with VLA policies, we build and evaluate DSWAM under the DeMaVLA real-world deformable manipulation setting with matched robot platform, pretraining data, post-training data, and evaluation criteria.

## 1. 核心问题与整体含义（研究动机与背景）

**研究背景：**

- **VLA（视觉-语言-动作）策略**是机器人操作领域的主流范式，通过单帧视觉观测和语言指令直接映射到动作，但缺乏对场景动态演化的时序建模能力。
- **WAM（世界动作模型）** 通过视频预测为动作学习提供密集的物理动态监督，在接触丰富的操作任务（如抓取、放置、可变形物体操作）中表现优异，但**缺少VLM式VLA的语言级规划接口**，无法将粗粒度用户指令分解为细粒度可执行子任务。

**两个核心痛点：**

1. **分解缺口（Decomposition Gap）** ：家庭任务通常涉及复杂多步目标，粗指令需要转换为有序的子任务序列，而现有WAM主要定位为执行策略，缺乏语义规划能力。
2. **公平对比缺失**：现有WAM与VLA的真实机器人对比常受数据源、机器人本体、任务协议差异干扰，难以判断性能差异究竟来自策略设计本身还是实验设置。

**研究意义：**
DSWAM提出"语义任务分解"与"世界感知物理执行"可解耦的理念——WAM保持强大执行引擎能力，而由独立的高层模块仅在指令需要时提供任务分解，从而兼顾物理执行精度与复杂任务语义理解。

## 2. 方法论：核心思想、关键技术细节

### 2.1 双系统架构总览

- **System 1（WAM执行器）** ：默认控制路径，基于预训练视频模型（Wan2.2-TI2V-5B）和动作专家（Action Expert），从多视角RGB图像、语言条件、本体感知状态预测连续动作块。
- **System 2（视觉-语言子任务规划器）** ：可选模块，基于Rynnbrain4B风格VLM，仅在任务分解有用时激活。接收短期视觉历史（最近5帧，1Hz采样）和全局任务提示，输出细粒度可执行子任务。

### 2.2 System 2 规划器设计

- **输入**：全局任务提示 `p` + 短时视觉历史 `Xt = {x_t-4, ..., x_t}`（5帧，1Hz）。
- **输出**：下一个子任务级指令 `s_t = Pφ(Xt, p)`。
- **子任务边界监督**：利用预训练VLM标注器将轨迹视频分割为子任务区间，训练目标是**转换感知的（transition-aware）**——窗口在子任务内部时输出当前子任务标签，窗口位于非终结子任务末尾时输出下一个子任务，终结子任务末尾输出"done"。
- **与System 1的耦合**：部署时每2秒同步一次，WAM执行器发送5帧给规划器，返回的子任务作为语言条件，直到下一次更新。

### 2.3 System 1 WAM执行器

- **编码**：`z_t = fθ(I_t^1:3, ℓ_t, q_t)`，单次前向传播提取潜在世界特征。
- **动作预测**：基于条件流匹配（Conditional Flow Matching）预测连续动作块，适合双臂操作的平滑轨迹生成，无需将机器人控制离散为语言token。
- **训练目标**：共享流匹配框架下的双重损失：
  - 动作损失：`L_act = L_FM(A_t)`
  - 视频协同训练损失：`L_vid = L_FM(V_t+1:t+T)`
  - 总损失：`L = L_act + λvid·L_vid`
- **关键设计**：视频协同训练仅作为训练期世界建模监督，推理时**不生成未来视频**，直接预测动作块——遵循Fast-WAM的"训练期受益、测试期免想象"方向。
- **防信息泄漏**：训练中动作token被阻止使用未来视觉token作为特权信息，保持与推理设置一致。

### 2.4 部署优化

- **TensorRT双引擎加速**：将视觉上下文引擎与动作去噪引擎分离，保留公共服务接口，采用BF16精度将端到端策略延迟从198.2ms降至73.8ms（2.69×加速），最大相对误差仅0.0106，余弦相似度0.99977。
- **实时分块（RTC）+ 异步执行**：策略worker从最新观测预测新块，控制器继续执行当前块，策略延迟不阻塞底层控制。
- **推理时机制**：RTC仅为部署手段，不改变训练方式（无动作条件化或后缀损失）。

## 6. 主要结论与发现

1. **WAM执行性能优于VLA**：在匹配的DeMaVLA真实折叠基准中（System 2禁用），DSWAM将平均成功率从DeMaVLA的92.5%提升至96.3%（+3.8%），平均完成时间从2'18"缩短至1'44"（-34秒）；相比π0提升更大（成功率+20%，时间-42秒）。
2. **仿真能力广泛**：RoboTwin 2.0上达到92.38%（干净）和91.90%（随机）平均成功率，在WAM类基线（Fast-WAM）基础上继续提升0.50%/0.12%，超越最强VLA基线（DeMaVLA）3.96%/5.12%。
3. **子任务监督提升稳定性**：在排序任务中，子任务级指令使成功率从75.7%提升至100%，错误数从每轮3.53降至0.65。
4. **高效部署可行性**：TensorRT+异步RTC将策略延迟降至73.8ms，在保持100%成功率的衬衫任务上缩短完成时间，并将裤子任务成功率从70%提升至100%——说明解耦策略推理与机器人控制可改善执行稳定性。
5. **双系统解耦设计有效**：原子指令可直接执行，复杂指令按需分解，避免了规划对简单任务的强制开销。

## 7. 优点

- **问题定位精准**：直击WAM的语义分解缺口和WAM-VLA公平对比缺失两大领域空白。
- **双系统架构设计优雅**：System 1/System 2解耦具有认知科学视角（快慢思维），在工程上实现了"按需规划、默认执行"的灵活控制流。
- **公平对比方法论贡献突出**：严格匹配DeMaVLA的机器人平台、数据、任务协议和评估标准，使真实对比结果具有高度可信度，是该领域稀缺的受控实验。
- **贴合部署实际**：采用"训练期视频协同、推理期无未来生成"策略，配合TensorRT双引擎和异步RTC，兼顾世界建模收益与实时性。
- **转换感知的子任务监督**：在子任务边界处预测下一子任务的训练策略具有创新性，学习到的不仅是识别当前子任务，更是何时切换。
- **验证充分且层次清晰**：从仿真到真实、从单一执行到系统级部署，实验链条完整。

## 8. 不足与局限

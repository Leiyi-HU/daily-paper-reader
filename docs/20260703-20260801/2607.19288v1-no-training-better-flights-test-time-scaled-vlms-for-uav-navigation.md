## 摘要
测试时缩放为视觉语言模型（VLM）提供了一种有前景的推理性能提升方法，且无需额外训练。现有的无人机（UAV）视觉语言导航（VLN）方法通常依赖于单次推理，在复杂环境中可能因产生次优或不安全的轨迹而失效。本文探索了一种简单有效的方法，将测试时缩放应用于无人机视觉语言导航。我们通过迭代细化过程增强导航推理，该过程无需额外模型训练，引导模型重新评估其初始导航计划以提高准确性和安全性。我们的方法首先提示模型生成多个并行候选，然后执行自我修正步骤，在不改变底层模型的情况下实现更深层次、更稳健的规划。为进一步加强决策，我们设计了一个多标准评分函数，基于安全性、目标对齐和前向进展来评估细化后的候选。这种简单而强大的组合使冻结的无人机导航视觉语言模型能够自我修正，生成更准确、更可靠的飞行计划，在该任务中实现了最先进的性能。

## Abstract
Test-time scaling offers a promising method to improve the inference performance of Vision-Language Models (VLMs) without additional training. Existing approaches to vision-language navigation (VLN) for Unmanned Aerial Vehicle (UAV) typically relies on a single inference pass, which can falter in complex environments by producing suboptimal or unsafe trajectories. In this paper, we explore a simple and effective approach to apply test-time scaling to VLN for UAV. We enhance navigation reasoning through an iterative refinement process that requires no extra model training, guiding the model to re-evaluate its initial navigation plan for better accuracy and safety. Our method first prompts the model to generate multiple parallel candidates and then performs a self-correction step, achieving deeper and more robust planning without changing the underlying model. To further strengthen decision-making, we design a multi-criteria scoring function to evaluate the refined candidates based on safety, goal alignment, and forward-progress. This simple yet powerful combination enables a frozen UAV navigation VLMs to self-correct and generate more accurate and reliable flight plans, achieving SOTA performance in this task.

## 2. 论文提出的方法论：核心思想、关键技术细节与流程

### 2.1 总体框架：Test-Time Explore–Refine–Select（探索–细化–选择）

论文提出一个三阶段推理框架，将**并行扩展**与**串行细化**有机结合，实现"广度优先、深度优化"的推理策略：

### 阶段一：并行探索（Parallel Exploration）

- 将多模态输入形式化为 I = (V, L)，其中 V = {v₁, v₂, ..., v_k} 为 k 个不同视角的视觉观测，L 为用户自然语言指令。
- 通过 N 次独立推理调用（并行采样），让 VLM 生成 N 个不同的初始候选航点：

  **cᵢ = F(I)，∀i ∈ {1, 2, ..., N}**

- 得到初始候选集合：

  **C_initial = {c₁, c₂, ..., c_N}**

- **设计意图**：利用 LLM 生成的随机性与不确定性，拓宽搜索范围，避免过早收敛到单一次优解。

### 阶段二：串行细化（Serial Refinement）

- 对每个初始候选点 cᵢ 执行 M 轮迭代自我校正，核心是**自我反思式提示（Self-Reflective Prompt）**。
- 关键设计细节：
  - 通过失败案例分析发现，无人机在初始阶段常常持续向下飞行并导致碰撞，因此首先在提示中加入**全局安全指令**；
  - 将初始航点坐标重新注入提示，并附带明确的自我校正指令（如"等一下，让我们重新考虑……"），迫使模型对初始方案进行批判性反思。
- 流程可形式化为：

  **c′ᵢ = R(I, cᵢ; T_prompt)**

  其中 T_prompt 是反思性提示模板，如：
  > "Wait, let's reconsider. An initial plan was to move towards [waypoints]. Based on the instruction and current view, let's re-evaluate and provide a better plan."

- 所有 N 个候选点都经过此过程后，得到精炼候选集合：

  **C_refined = {c′₁, c′₂, ..., c′_N}**

### 阶段三：评分与选择（Scoring & Selection）

- 设计**多准则评分函数**，从三个核心维度综合评价每个精炼候选点：

  **Score_total(c′ᵢ) = w_obs · S_obs + w_tar · S_tar + w_prog · S_prog**

  权重设定为 w_obs = 0.5、w_tar = 0.3、w_prog = 0.2，确保**安全性为最优先考量**。

- **安全性评分（S_obs）**：
  - 利用无人机携带的多方向深度图像（前、后、左、右、下共 K 个视角）；
  - 取每个深度图中心区域（RoI）的最小深度值，再取所有方向的最小值作为安全距离 d_safe；
  - 使用对数函数进行非线性变换：**S_obs = log(d_safe + 1)**，使得接近障碍时分数急剧下降。

- **目标对齐评分（S_tar）**：
  - 计算候选方向向量 v_cand = p_c − p_curr 与目标方向向量 v_tar = p_tar − p_curr 的余弦相似度；
  - 线性变换至 [0, 1] 区间：**S_tar = ½(cosine_similarity + 1)**。

- **前向进展评分（S_prog）**：
  - 使用候选点与当前位置的欧氏距离 d_prog；
  - 通过双曲正切函数归一化：**S_prog = tanh(d_prog / α)**，α 取 10.0，控制饱和速度，避免过远但危险的候选点主导决策。

- **最终决断**：选择总分最高的候选点作为最终导航决策：

  **w_best = argmax Score_total(c′ᵢ)**

### 整体思路总结

核心思想是让**冻结的 VLM** 通过"先并行发散、再串行深入、后多准则裁决"的流程，在不改变任何模型参数的情况下，仅通过调整推理时的计算策略和提示设计，显著提升导航规划质量。

### 3.2 对比方法

- **Random**：完全随机路径选择，无规划能力。
- **Fixed Action**：基于规则的非学习方法，将指令关键词映射到预定义离散动作（如"cruise"→前飞 5 米）。
- **CMA**：基于跨模态注意力机制的经典 VLN 模型。
- **TravelUAV**：基于 LLM 的多模态导航方法，采用分层轨迹生成机制（先规划宏观目标点，再结合前视图生成细粒度轨迹），提供 L1/L2/L3 三种助手模式，实验中统一使用 L1 模式。

### 3.3 评估指标

- **NE（Navigation Error）**：无人机最终位置与目标点的距离差（越低越好）；
- **SR（Success Rate）**：任务成功率（越高越好）；
- **OSR（Oracle Success Rate）**：无人机保持正确总体航向但未到达目标的概率（越高越好）；
- **SPL（Success weighted by Path Length）**：成功时路径效率（越高越好）。

- 环境：Python 3.10（Conda 虚拟环境 llamauav）、PyTorch 2.0.1、Ninja 编译器、特定版本 Flash-Attention 库。

## 6. 论文的主要结论与发现

1. **提出的三阶段测试时缩放框架（Explore–Refine–Select）在所有标准测试集上均达到 SOTA**：
   - TS 集：SR 提升 2.02%，SPL 提升 1.43%，OSR 提升 2.47%，NE 降低 4.67%；
   - UO 集：SR 提升 1.28%（较 TravelUAV）；
   - UM 集：SR 提升 0.94%（较 TravelUAV）。
2. **并行扩展和串行细化均独立有效**，且两者结合产生**协同效应**——Par=3 + Ser=2 的组合优于任何单一维度的扩展方式。
3. **计算预算与导航精度正相关**：随着推理阶段 token 消耗量从 6,705 增至 38,315，SR 从 22.94% 稳定提升至 24.96%，验证了测试时缩放的基本前提——分配更多推理计算能换取更好的决策质量。
4. **VLM 在复杂导航决策中存在显著不确定性**：可视化表明，同一输入下模型生成的候选点呈现分散聚类而非收敛于单点，传统单步推理的随机采样会导致决策不稳定，而并行探索能系统性地捕获并利用这种多样性。
5. **在未见物体和未见场景上的增益小于已见场景**，说明分布偏移会增加任务难度，但框架仍具备一定的泛化能力。

## 7. 优点

- **不改变底层模型、零额外训练成本**：方法完全作用于推理阶段，利用冻结 VLM 的自我反思能力，具有极强的实用性和即插即用性。
- **方法简单而有效**：并行采样 + 自我修正提示 + 多准则评分，三阶段设计逻辑清晰，每个组件都有明确作用，并通过消融验证。
- **将测试时缩放的两种策略（串行/并行）有机结合**：避免了单一策略的局限，体现了"广度 × 深度"的协同增益，是对测试时缩放理论的良好实践扩展。
- **多准则评分函数设计细致**：
  - 安全性评分采用多方向深度图的最小值，并通过对数函数放大近距离障碍的风险信号；

- **失败案例驱动的提示设计**：通过在真实失败案例中观察模式（无人机持续俯冲导致碰撞），针对性地加入全局安全指令，具有较强的工程实践价值。

- **仅停留在仿真环境验证**：所有实验基于 AirSim 模拟环境，尚未在真实无人机平台上部署验证。仿真与真实世界在视觉渲染保真度、物理引擎动力学、传感器噪声特性、通信延迟以及外部环境干扰等方面存在明显差距，因此框架在真实部署场景中的有效性与安全性仍需进一步检验。此外，论文未讨论该推理框架在无人机端侧（如机载嵌入式设备）运行时的计算负载与实时性问题。

## 9. 总结性与展望性评价

- **整体定位**：该论文为无人机视觉语言导航提供了一种新颖且实用的推理阶段优化路径。其核心价值在于，它没有沿着主流“改进架构/扩大训练”的路线推进，而是将测试时缩放（Test-Time Scaling）的思想移植到具身导航任务中，通过“并行探索—串行细化—多准则选择”三阶段设计，在不改变模型参数、不增加训练成本的前提下实现了性能提升，体现出较强的即插即用与工程落地潜力。
- **方法学启示**：论文用具体证据表明，VLM 在导航规划任务中天然存在输出不确定性（同一输入产生多样性候选），而这种不确定性并非单纯是噪声，而可以被主动地采样、评估并利用。这一视角对更广泛的机器人决策任务（如自动驾驶、机械臂操作等）具有启发意义。
- **值得关注的后续研究方向**（论文提及或自然延伸）：
  - 自适应计算分配：根据任务难度或实时环境动态调节并行数与串行深度，避免统一配置导致的算力浪费；
  - 评分函数可学习化：用可学习的评判器替代人工设定权重与固定准则，提升框架对不同场景的适应性；
  - 更深层串行迭代行为研究：探索更长的自我反思链是否持续增益，或如何设定终止条件来规避收益递减与发散；
  - 真实无人机部署测试：验证框架在物理世界中的鲁棒性、延迟表现与安全边界；
  - 向其他 VLM 骨干迁移：验证框架在更大/不同规模基座模型上的通用性，以及基座模型能力对测试时缩放收益上限的影响。

## 摘要
视觉基础模型越来越多地被用作下游视觉识别的冻结骨干网络，这使得参数高效适配成为一个核心问题。基于提示的适配方法，包括视觉提示微调（VPT），为专门化这些模型提供了一种轻量级方式，但其逐层行为仍未被充分理解：性能对提示深度、位置和任务分布敏感，且在标准域内基准上的增益并不总能转化为稳健的泛化。我们认为，这一限制并不仅仅是优化问题，而是层级信息分配问题：现有的基于提示的方法缺乏对提示条件表示应在跨深度上保留、抑制和传播什么的原则性控制。受信息瓶颈原理的启发，我们引入了提示信息瓶颈（PIB），这是一个对逐层压缩-充分性权衡进行正则化，并促进更连贯的跨层信息路径的框架。关键思想在于，有效的适配应是最小但充分的，在较早层保留与任务相关的局部证据，同时在较深层逐步丢弃干扰因素和冗余细节。大量实验表明，PIB在34个数据集上取得了强性能，在FGVC上达到92.1%，在HTA上达到93.01%，在VTAB-1k上达到77.33%，同时在主要设置中平均仅微调0.35%的参数。除了基准准确率之外，PIB还有助于解释提示容量扩展的非单调行为，减少捷径依赖，并在分布偏移和细粒度识别设置下提高鲁棒性。这些结果使PIB既成为一种实用方法，也为适配冻结视觉基础模型提供了一个信息分配视角。我们的代码可在 https://github.com/itsnotacie/MM-26-PIB 获取。

## Abstract
Vision foundation models are increasingly reused as frozen backbones for downstream visual recognition, making parameter-efficient adaptation a central problem. Prompt-based adaptation, including Visual Prompt Tuning (VPT), provides a lightweight way to specialize these models, but its layer-wise behavior remains poorly understood: performance is sensitive to prompt depth, placement, and task distribution, and gains on standard in-domain benchmarks do not always translate into robust generalization. We argue that this limitation is not solely an optimization issue, but a layer-wise information allocation issue: existing prompt-based methods lack principled control over what prompt-conditioned representations should preserve, suppress, and propagate across depth. Inspired by the Information Bottleneck principle, we introduce Prompted Information Bottlenecks (PIB), a framework that regularizes layer-wise compression-sufficiency trade-offs and promotes a more coherent cross-layer information path. The key idea is that effective adaptation should be minimal yet sufficient, retaining task-relevant local evidence in earlier layers while progressively discarding nuisance factors and redundant details in deeper layers. Extensive experiments show that PIB achieves strong performance across 34 datasets, reaching 92.1% on FGVC, 93.01% on HTA, and 77.33% on VTAB-1k, while tuning only 0.35% parameters on average across the main settings. Beyond benchmark accuracy, PIB helps explain the non-monotonic behavior of prompt capacity scaling, reduces shortcut reliance, and improves robustness under distribution shift and fine-grained recognition settings. These results position PIB as both a practical method and an information-allocation perspective for adapting frozen vision foundation models. Our code is available at https://github.com/itsnotacie/MM-26-PIB

## 论文提出的方法论

### 核心思想

受信息瓶颈（Information Bottleneck, IB）原理启发，PIB 将提示微调视为逐层信息分配过程。理想情况下，有效适配应遵循“**最小但充分**”的信息路径：较早层保留任务相关局部证据，较深层逐步丢弃干扰因素与冗余细节，最终形成连贯的跨层语义精炼过程。

### 问题建模

在 VPT 式适配中，提示条件化表示逐层生成：

- H_l = f_l(H_{l-1}, P_l)，其中 f_l 为冻结的第 l 个 Transformer 块，P_l 为该层提示参数；
- 最终预测通过任务头 g(H_L) 产生；
- 标准提示微调仅优化任务损失 L_task，未对中间表示的保留/抑制进行任何约束。

### 理想化 IB 目标

受经典 IB 目标 min I(Z;X) − β I(Z;Y) 启发，PIB 将目标扩展为对逐层表示链 H_1, …, H_L 的联合优化：

- 最小化解 ∑ [ I(H_l; X) − β_l I(H_l; Y) ]。

由于精确互信息优化在深层 Transformer 中不可行，PIB 引入可计算的代理损失。

### 关键技术细节

1. **压缩项（Compression）**：
   - 对每层隐藏表示做行归一化，计算经验相关矩阵 C_l；
   - 压缩损失定义为 C_l 与单位矩阵差的非对角线能量，即 L_comp = ‖C_l − I_d‖²_F, off；
   - 目标：抑制特征维度间的冗余共激活，推动表示更紧凑。

2. **充分性项（Sufficiency）**：
   - 基于类可分性定义：类内散布 S_intra 与类间散布 S_inter 的比值；
   - L_suff = S_intra / (S_inter + ε)；
   - 目标：在压缩的同时保持类别判别结构，防止过度压缩破坏任务相关信息。

3. **跨层最小-充分路径正则化（L_path）**：
   - 定义每层质量分数 q_l = L_comp + α_l L_suff；
   - 路径损失为相邻层质量分数退化超过容忍裕度 δ_l 的惩罚：L_path = Σ max(0, q_{l+1} − q_l − δ_l)；
   - 目标：防止层间权衡的突变，促进从局部证据保留到语义选择性的平滑过渡。

4. **可选层感知路由（Layer-aware Routing）**：
   - 引入每层可学习门控 r_l ∈ [0,1]，对压缩与充分性损失按层加权；
   - L_route = Σ [ r_l λ_l L_comp + (1−r_l) γ_l L_suff ]；
   - 门控参数与提示参数联合优化，允许不同层自适应选择不同信息分配策略。

### 最终目标

- L_total = L_task + L_PIB + η L_path；
- 训练中仅更新提示参数、任务头及可选路由变量，骨干保持冻结。

## 论文的主要结论与发现

- **PIB 在参数高效性方面效果显著**：在 34 个数据集上，平均仅微调 0.35% 参数，FGVC 达到 92.1%、HTA 达到 93.01%、VTAB-1k 达到 77.33%，超过现有提示微调方法；在 MAE/MoCo v3 预训练和 Swin-Base 架构上也保持优势；
- **验证层级信息分配视角的有效性**：PIB 产生更平滑的信息轨迹、更稳定的冗余抑制、更强的类可分性和更有序的跨层路径，支持“提示微调的局限在于缺乏信息分配控制”的核心论点；
- **解释了提示容量扩展的非单调行为**：更多提示深度或长度并不保证更好迁移；PIB 通过信息正则化使缩放趋势更平滑稳定；
- **降低捷径依赖、提升鲁棒性**：在前景主导评估下提升明显，在后景-only 评估下准确率降低，说明对背景线索依赖减少；在损坏输入、域偏移和少样本场景下平均衰减从 8.0 降至 5.3 个百分点；
- **注意力行为更结构化**：PIB 的注意熵演化更平滑，深层注意呈现更清晰的块状组织，提示-补丁注意力从早期多样化探索逐步转为后期协调聚焦。

## 优点

- **视角新颖**：将提示微调问题从“提示结构设计”提升到“层级信息分配”的层面，为理解 PEFT 行为提供了新的理论透镜；
- **方法轻量且实用**：不引入额外网络模块或推理开销，额外训练代价较小，保持冻结骨干参数高效适配的优势；
- **代理损失设计合理且有理论依据**：压缩与充分性的分解既对应 IB 的直觉目标，又兼顾计算可行性；
- **实验设计系统**：多骨干、多预训练范式、多难度层级的数据集体系，结合缩放分析、消融、鲁棒性和诊断实验，证据链完整；
- **可解释性分析较扎实**：从注意力熵、注意力 logits、提示-补丁交互多角度验证方法的行为与动机一致；
- **泛化验证充分**：涵盖自监督/监督预训练、层级/普通 Transformer 架构，显示方法适用面广。

## 不足与局限

- **算力信息缺失**：未报告 GPU 型号、数量与训练时长，影响可重复性和算力成本评估；
- **任务类型有限**：所有实验均为分类任务，未涉及目标检测、分割、多模态等场景，“充分性”的定义依赖类可分性，对非分类任务的适用性尚不清楚；
- **代理损失非精确互信息**：压缩与充分性均为结构化启发式代理，并非精确的互信息估计；在追求更严格 IB 理论连接时仍有改进余地；

- **失效场景未量化**：论文指出在接近预训练分布的任务上提升有限，但未明确界定此类场景的边界条件。

## 摘要
连续环境中的视觉与语言导航（VLN-CE）要求智能体在低延迟执行动作的同时，维护长时程的视觉历史以保持轨迹一致性。现有的基于视频的VLN方法通常难以同时满足这两个需求。为解决这些挑战，我们提出了MemVLN，一种新颖的VLN框架，以实时推理效率（14 FPS）实现了最先进的性能。MemVLN利用视觉编码器处理连续观测，并使用大语言模型（LLM）解释指令和生成动作。我们方法的核心是一种采用金字塔分辨率的情景记忆管理机制。该机制将计算集中在即时感知上，同时保留压缩的长期历史。作为该设计的补充，我们引入了程序记忆，通过紧凑的原子级中层动作词汇表实现快速动作，从而绕过自回归解码延迟。在VLN-CE上的实验表明，MemVLN-4B在R2R中比基线Qwen3-VL-4B架构的SR提高了5.8%，在RxR中提高了9.7%，同时推理延迟实现了7倍加速。

## Abstract
Vision-and-Language Navigation in Continuous Environments (VLN-CE) requires agents to maintain long-horizon visual history for trajectory consistency while executing actions with low latency. Existing video-based VLN approaches typically struggle to satisfy both demands simultaneously. To address these challenges, we propose MemVLN, a novel VLN framework that achieves state-of-the-art performance with real-time inference efficiency (14 FPS). MemVLN utilizes a visual encoder to process continuous observations and a Large Language Model (LLM) to interpret instructions and generate actions. Central to our approach is an Episodic Memory management that applies pyramidal resolutions. This mechanism concentrates computation on immediate percepts while retaining compressed long-term history. Complementing to this design, we introduce Procedural Memory for fast action with a compact vocabulary of atomic mid-level actions to bypass auto-regressive decoding latency. Experiments on VLN-CE show that MemVLN-4B surpasses the baseline Qwen3-VL-4B architecture by 5.8\% SR in R2R and 9.7\% SR in RxR, while achieving a 7$\times$ speedup in inference latency.

  - **长时程视觉历史的维护**：用于保持轨迹一致性、防止路径漂移；
  - **低延迟动作执行**：用于实时控制与响应。
- **核心矛盾**：现有的LVLM类视频导航模型难以同时兼顾上述两点。部分方法（如NaVILA）仅均匀采样固定数量的帧（如8帧），牺牲了时间密度；另一些方法（如Uni-Navid、StreamVLN）通过token合并/池化压缩视觉token，虽降低计算成本，但这种潜在空间中的不规则融合破坏了二维空间网格结构，与M-RoPE、DeepStack等现代架构设计存在根本性冲突。
- **研究意义**：论文旨在解决“长视频上下文”与“实时响应”之间的根本矛盾，提出一种受生物记忆机制启发的VLN框架，在不依赖深度传感器或里程计的前提下，仅凭单目RGB视频流实现实时导航。

## 2. 论文提出的方法论

### 2.1 总体框架
MemVLN 由三部分组成：
- **视觉编码器**：处理连续的RGB观测；
- **大语言模型（LLM）**：解析指令、生成动作决策（采用Qwen3-VL作为骨干）；
- **双记忆机制**：情景记忆（Episodic Memory）+ 程序记忆（Procedural Memory）。

### 2.2 情景记忆：金字塔分辨率机制（Pyramidal Resolution）

**动机来源**：对观测注意力分布的分析揭示：最近的4个观测占全部视觉注意力权重的50%以上；注意力得分随观测的新近度显著增加。这说明VLN中近期观测承担关键决策信息，而早期观测大多被忽略。

**核心设计**：模仿人类记忆的时间粒度偏差（近期事件保真度高、远期经验逐渐压缩），将历史帧划分为三个时间层级：
- **immediate（即时层）** ：T−Bshort 到 T−1 帧 → 高分辨率（512×512）；
- **short-term（短期层）**：T−Blong 到 T−Bshort 帧 → 中分辨率（256×256）；
- **long-term（长期层）**：0 到 T−Blong 帧 → 低分辨率（128×128）。

分辨率调整公式：

**v′t = Rescale(vt, rtier)**，其中 rimm > rshort > rlong。

**关键设计原则**：调整 rlong 和 rshort，使整个长时历史序列的累计token数不超过单帧即时观测的token数，从而在固定上下文约束下显著扩展“回溯窗口”。

**与Token Merging的本质区别**：
| 维度 | Token Merging（现有方法） | 金字塔分辨率（本文） |
|------|--------------------------|---------------------|
| 压缩位置 | 潜在空间（latent space） | 原始像素空间 |
| 聚类依据 | 语义相似性 | 时间层级 |
| 空间拓扑 | 破坏均匀2D网格 | 保持严格均匀拓扑 |
| 兼容性 | 与M-RoPE冲突 | 完全兼容M-RoPE/DeepStack |

**变体探索**：论文比较了U形、递减、递增三种金字塔曲线，发现递增型（强调近期）最佳，与注意力分析结论一致。

### 2.3 程序记忆：快速动作机制（Fast Action）

**动机来源**：推理延迟分析（表1）显示，VLN的延迟瓶颈来自LLM的自回归解码本质——首token预填充时间较长，后续每个token的生成时间随输出token数线性增长。

**核心设计**：借鉴程序记忆（长期内隐记忆，自动执行技能），将导航重新构建为**一次性中层动作预测任务**：
- 定义紧凑的**原子中层动作词汇表** Aaug（见表8），包括：停止、前进短/中/长距离（25/50/75cm）、左/右转15°/30°/45°；
- 将LLM原始词汇表中的单个token重新映射（re-purpose）为这些增强动作token；
- 每个token封装一个完整的中层动作或短时动作序列，从而**将多token自回归解码压缩为单次前向预测**。

**效果**：
- 推理延迟从 >300ms 降至约70ms；
- 推理速度从2 FPS提升至14 FPS（7×加速）。

1. **性能最优**：MemVLN-8B在R2R上达到65.3% OS、58.4% SR；在RxR上达到66.0% SR、57.3% SPL，均超越现有SoTA（StreamVLN-7B：R2R SR 56.9%，RxR SR 52.9%）。

3. **单目RGB可行性**：仅依赖单目RGB输入（不使用深度、里程计等传感器）即可超越使用更丰富观测信息的基线，验证了LVLM知识迁移的有效性。
4. **跨数据集泛化**：仅在R2R上训练，在RxR上零样本评估，SR较NaVILA提升12%，SPL提升20%。
5. **注意力分析的价值**：观测注意力集中在近期帧的发现，为金字塔分辨率设计提供了经验依据。
6. **DAgger数据的价值**：交互式、on-policy数据对导航鲁棒性具有显著增益（RxR上SR提升3.5%）。
7. **RxR上性能更优的原因**：RxR的指令更详细，提供了更强的语义锚定，使智能体保持在正确路径上。

## 7. 优点

- **生物启发的记忆机制**：首次将情景记忆与程序记忆的认知科学概念系统性地引入VLN-CE，设计新颖且自然。
- **算-存平衡的精巧设计**：金字塔分辨率在不增加token预算的前提下扩展了时间回溯窗口，用一种简单优雅的方式解决了“历史长度-计算代价”的矛盾。
- **对现代架构的高度兼容**：相比token merging方法，在原始像素域下采样保证了与M-RoPE、DeepStack等先进backbone的兼容性，这一点具有工程实践上的重要价值。
- **实验充分且结果突出**：在两大标准benchmark上均刷新SoTA，且跨数据集泛化表现优异；消融实验覆盖了方法各组成部分。
- **兼顾性能与效率**：4B模型（较小参数量）同时实现高精度和14 FPS实时推理，表明方法的实际部署潜力。
- **自回归瓶颈的直接解决**：通过单token动作词汇将多步解码压缩为单步预测，直击VLN系统延迟的核心痛点。
- **洞察驱动的设计**：从注意力权重分析出发指导记忆机制设计，而非盲目堆砌组件。

## 8. 不足与局限

1. **计算资源门槛高**：需要H200级别的高端GPU（8×140GB），训练成本较高，对于资源有限的学术团队来说复现难度较大。
2. **边缘部署受限**：虽然实现14 FPS实时推理，但仍依赖GPU加速，在轻量级边缘设备或低功耗移动机器人上难以直接部署。
3. **消融覆盖不全**：
   - 消融仅在4B模型上进行，未验证设计在8B模型上的普适性；
   - 未消融不同backbone（如仅验证了Qwen3-VL）的泛化性；
   - 未给出长时记忆下限的分析（如最小时域回溯窗口需求）。
4. **实验偏差风险**：
   - 训练数据多样性（人类轨迹+ScaleVLN）在单独加入时导致性能下降，但论文保留了这些数据，增加了评测的混杂因素；
   - 与部分基线（如waypoint-based方法）使用的训练语料和数据规模存在显著差异，严格意义上对比不够对等；
   - RxR上的部分收益可能来自指令的更详细语义而非方法本身的导航能力。
5. **模拟-现实差距**：仅在Habitat模拟器中进行评估，虽然采用连续动作空间，但未在真实机器人上部署验证。
6. **动作空间受限**：原子动作词汇表（前进三种距离+转向三种角度）能否覆盖真实世界中更复杂的运动控制需求（如后退、侧移、变速运动等）尚待验证。
7. **注意力分析的推广性**：基于单步随机采样的注意力分析结论是否在不同场景和任务中具普适性，还需更多统计证据。

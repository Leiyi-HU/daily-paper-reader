## 摘要
智能体视觉推理的根本目标是提高多模态大语言模型（MLLMs）在复杂任务上的成功率，而非仅仅为其配备一种复杂却低效的推理范式。在这项工作中，我们通过工具使用的两个关键维度重新思考智能体视觉推理：模式自适应性（MA）和工具效应（TE）。模式自适应性刻画了MLLM能否识别工具何时真正必要并相应调用它们，从而在提升需要工具辅助的挑战性问题性能的同时，避免不必要的计算开销。工具效应刻画了工具使用的实际影响：工具应当扩展模型在仅通过文本推理无法解决的问题上的能力，同时在模型无需工具即可解决的问题上避免引入额外错误。我们进行了全面分析以量化这两个属性，并实证揭示现有智能体视觉推理模型表现出有限的模式自适应性，而工具使用在困难样本上带来的收益在很大程度上被其在模型本已能够解决的简单样本上引入的损害所抵消。受这些观察启发，我们提出了Beacon，一种新颖的智能体视觉推理模型，它实现了更强的整体性能、改进的模式自适应性以及真正的工具诱导性能提升。Beacon的核心是强化学习阶段中的必要性感知自适应奖励和提示引导的能力扩展机制，它们分别鼓励基于任务必要性进行自适应工具调用，并增强模型在最具挑战性问题上的工具使用能力。跨多个基准的大量实验证明了Beacon强大的整体性能及其在模式自适应性和工具效应两方面的显著改进。

## Abstract
The fundamental goal of agentic visual reasoning is to improve the success rate of multimodal large language models (MLLMs) on complex tasks, rather than merely equipping them with a sophisticated yet inefficient reasoning paradigm. In this work, we rethink agentic visual reasoning through two key dimensions of tool use: Mode Adaptiveness (MA) and Tool Effect (TE). Mode Adaptiveness characterizes whether an MLLM can recognize when tools are truly necessary and invoke them accordingly, thereby avoiding unnecessary computational overhead while improving performance on challenging problems that require tool assistance. Tool Effect characterizes the actual impact of tool use: tools should extend the model's capabilities on problems unsolvable through text-only reasoning, while avoiding additional errors on problems that the model can already solve without tools. We conduct a comprehensive analysis to quantify these two properties and empirically reveal that existing agentic visual reasoning models exhibit limited Mode Adaptiveness, while the gains produced by tool use on hard examples are largely offset by the harm introduced on easy examples that the models can already solve. Motivated by these observations, we propose Beacon, a novel agentic visual reasoning model that achieves stronger overall performance, improved Mode Adaptiveness, and genuine tool-induced performance gains. At the core of Beacon are the Necessity-Aware Adaptive Reward and the Hint-Guided Capability Expansion mechanism in the reinforcement learning stage, which respectively encourage adaptive tool invocation based on task necessity and strengthen the model's tool-use capability on the most challenging problems. Extensive experiments across diverse benchmarks demonstrate the strong overall performance of Beacon and its substantial improvements in both Mode Adaptiveness and Tool Effect.

- **整体意义**：该论文主张，智能体视觉推理的进展不应仅以"模型是否用工具"来衡量，而应以"模型是否知道何时需要工具"以及"工具是否带来真实能力扩展"来衡量，并据此提出了系统性的分析框架和解决方案。

## 2. 论文提出的方法论

### 核心思想
Beacon 采用 **SFT 冷启动 → 强化学习（RL）微调** 的训练范式，在强化学习阶段引入两项核心机制，分别针对"何时用工具"和"如何用工具解决难题"：

### 关键技术细节

**（1）训练数据构建**
- **源数据选择**：从 16 个公开数据集收集数据（如 Geometry3K、OlympiadBench、HRScene、CV-Bench、MMMU、MuirBench、AgentVista、Vero 等），覆盖 STEM、图表理解、感知、智能体工具使用、通用视觉推理五大类任务。
- **SFT 数据合成**：先用基础模型 Qwen3-VL-8B-Instruct 采样 5 次，仅保留答对不超过 2 次的困难样本；再使用 Gemini 3.1 Pro 为这些样本生成含代码调用与中间观测的推理轨迹；最后用同一模型对轨迹进行精炼（去除冗余代码调用、补充缺失的观测、丢弃未真正依赖工具结果的轨迹）。
- **RL 数据构建**：用 SFT 模型在同一数据池上采样 5 次，保留答对不超过 3 次的样本作为 RL 训练集。
- **纯文本轨迹注入**：在 SFT 数据中注入基础模型正确生成的纯文本推理轨迹（来自 5 次采样中正确率 ≥ 0.6 的样本），以避免模型偏向工具调用并缓解灾难性遗忘。

**（2）必要性感知自适应奖励（Necessity-Aware Adaptive Reward, NAAR）**
- **核心思想**：在推理模式选择上实现"软偏好"而非"硬禁止"。
- **奖励设计**：对每个 roll 组 G，定义 Itext(G) = 该组中是否存在至少一条正确的纯文本回答。奖励定义为：
  - 若组内存在正确纯文本回答（Itext=1）：正确的纯文本回答奖励为 1，正确的代码辅助回答奖励为 0.25，其余为 0；
  - 若组内无正确纯文本回答（Itext=0）：正确的代码辅助回答奖励为 1，其余为 0。
- **意义**：当问题可通过文本推理解决时，鼓励模型采用纯文本推理（效率优先）；当纯文本推理不够用时，代码工具获得完整奖励（能力优先）。

**（3）提示引导的能力扩展（Hint-Guided Capability Expansion, HCE）**
- **动机**：传统 RLVR 中，困难样本的 rollout 若全错，则梯度信号无效，造成样本浪费。
- **具体实现**：
  - 先用当前策略对每个问题进行 8 次 rollout，若全部错误，则认定为难样本；
  - 调用 Gemini 3.1 Pro 先生成完整正确的代码推理轨迹，再由专家模型从中提取**不包含答案**的提示（包含关键推理步骤、期望子目标、工具使用策略）；
  - 将提示附加到原始问题后再次采样 N 个响应；
  - 策略优化时，训练轨迹保留但输入中去除提示（仅保留在旧策略的上下文里以缓解 off-policy 问题），从而将提示引导下的能力迁移回无提示的策略。
- **重要性采样比**：正常组和历史提示组采用不同的 importance-sampling ratio 计算方式，核心在于将训练时使用的提示从输入中扣除，使模型在推理时不依赖提示。

**（4）最终训练目标**
- 采用 GRPO 作为基础 RL 算法，将格式奖励（format reward）与 NAAR 加权组合（0.1 格式 + 0.9 自适应），再计算组内相对优势（group-relative advantage），最后使用标准的带裁剪的 GRPO 目标进行优化。
- 过滤掉所有响应全对、全错或推理模式单一（无自适应信号）的组，以提升训练效率。

- **发现 1（现有模型问题）**：现有智能体视觉推理模型在工具可用时相比纯文本推理几乎没有显著增益；它们在模式选择上缺乏自适应性，MA 均值接近甚至低于随机基线（50%）；工具在困难样本上的增益（Tool-Gain）基本被简单样本上的损害（Tool-Harm）抵消，ΔTE 接近零。

## 7. 优点

- **问题定义清晰**：将"何时用工具"和"工具是否有效"两个维度（MA 和 TE）形式化为可量化指标，为智能体视觉推理提供了统一且可复用的评估框架。
- **奖励设计巧妙**：NAAR 采用软偏好机制（正确代码辅助只给部分奖励而非零奖励），避免了自适应目标与任务正确性目标之间的冲突；基于组内是否有正确文本回答来自适应标注"文本"或"代码"标签，完全在线产生，避免了教师模型引入的分布偏差。
- **HCE 机制创新**：通过专家提示引导困难样本的 rollout 探索，并将提示引导下的能力迁移回无提示策略，有效缓解了 RLVR 在困难样本上学习信号不足的问题。
- **训练数据工程完善**：数据合成采用"基座模型筛选 → 专家生成轨迹 → 轨迹精炼"的三阶段流程，并注入纯文本轨迹防止代码偏好，细节扎实。
- **训练动态分析深入**：不仅报告最终指标，还分析了训练过程中模式选择的演变、困难组转化率等动态趋势，说服力强。

## 8. 不足与局限

- **自适应性仍有偏置**：Beacon 的 MA_text 仅为 22.91%，显著低于其他偏好纯文本推理的模型（如 Thyme、CodeV 的 77%+ 和 85%+），说明其在简单问题上仍然过度倾向于调用工具，效率与理论最优仍有差距。
- **基座模型规模有限**：仅使用 8B 规模模型，未验证在更大模型上的有效性与泛化性。
- **Gemm 3.1 Pro 依赖**：数据合成、轨迹精炼、提示生成均依赖 Gemini 3.1 Pro（闭源模型），这带来了成本问题，且若教师模型本身存在对特定任务类型的系统性偏差，生成的轨迹也会继承这类偏差，对开源生态的复现构成障碍。
- **评估领域有限**：虽然覆盖 13 个基准，但未涉及视频理解、多图交互推理、实时交互式 agent 场景等前沿方向。
- **提示提取细节待完善**：HCE 的提示生成依赖专家轨迹的正确性，且当前实现仅使用 "hint" 字段，工具步骤和子目标细节保留留作未来工作；同时论文未充分讨论提示被模型在推理时隐式记忆或依赖的风险边界。

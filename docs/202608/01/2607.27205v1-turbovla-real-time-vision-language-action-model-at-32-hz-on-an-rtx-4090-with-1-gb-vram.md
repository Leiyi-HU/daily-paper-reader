## 摘要
视觉语言动作（VLA）模型通常采用以LLM为核心的V→L→A路径，即先将视觉观测映射到大语言模型的表示空间中，再解码为机器人动作。虽然这种方法有效，但每次策略调用时都会产生大量的计算和内存开销。在这项工作中，我们提出了TurboVLA，一种新的VLA范式，将传统的V→L→A路径重构为直接的V+L→A映射。TurboVLA不使用大语言模型作为感知与动作之间的核心接口，而是独立编码视觉观测和语言指令，通过轻量级的双向视觉-语言交互直接交换信息，并使用紧凑的解码器预测连续的动作块。这种简单的设计直接从视觉和语言特征中构建任务条件表示，显著降低了VLA推理的计算和内存成本。在LIBERO上，TurboVLA仅用0.2B参数，在消费级RTX 4090上实现了97.7%的平均成功率、31.2毫秒的推理延迟和0.9 GB的推理显存，与规模大得多的VLA策略相当或更优。这些结果表明，TurboVLA是主流的以LLM为核心的VLA范式的简单有效替代方案，为如何连接视觉、语言和动作以实现高效机器人操作提供了新视角。代码可在https://github.com/H-EmbodVis/TurboVLA获取。

## Abstract
Vision-language-action (VLA) models commonly adopt an LLM-centric $V \to L \to A$ pathway, where visual observations are projected into the representation space of a large language model before being decoded into robot actions. Although effective, this design incurs substantial computation and memory overhead at every policy invocation. In this work, we introduce TurboVLA, a new VLA paradigm that reformulates the conventional $V \to L \to A$ pathway as a direct $V + L \to A$ mapping. Instead of using a large language model as the central interface between perception and action, TurboVLA independently encodes visual observations and language instructions, directly exchanges information between them through lightweight bidirectional vision-language interaction, and predicts continuous action chunks with a compact decoder. This simple design constructs task-conditioned representations directly from visual and linguistic features, significantly reducing the computational and memory costs of VLA inference. On LIBERO, TurboVLA achieves 97.7% average success with only 0.2B parameters, 31.2 ms inference latency, and 0.9 GB inference VRAM on a consumer-grade RTX 4090, matching or outperforming substantially larger VLA policies. These results establish TurboVLA as a simple and effective alternative to the prevailing LLM-centric VLA paradigm, offering a new perspective on how vision, language, and action can be connected for efficient robotic manipulation. Code is available at https://github.com/H-EmbodVis/TurboVLA.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **LLM-centric VLA 范式及其瓶颈**：现有视觉-语言-动作（VLA）模型普遍采用以大型语言模型（LLM）为中心的 `V → L → A` 路径——视觉观测先被投影到 LLM 的表示空间中，再与语言指令联合处理，最后解码为动作。此类设计依赖数十亿参数的 LLM 作为感知与动作之间的核心接口，带来以下问题：
  - 推理延迟高（每次策略调用都需经过整个大模型前向传播）；
  - GPU 显存占用大（数 GB 至十几 GB）；
  - 部署成本高，难以在资源受限的机器人平台上实时运行。
- **核心问题**：执行层面的机器人操作是否必须依赖 LLM 作为中心接口？论文认为，对于已经由指令明确指定操作技能的**执行级控制**任务，策略并不需要开放式的语言生成或自主任务分解，仅需利用指令确定当前视觉证据如何引导动作，因此存在更简洁高效的设计空间。
- **本文立场**：提出一种替代范式，将 `V → L → A` 重构为直接的 `V + L → A` 映射，在保留语言条件控制能力的同时，移除 LLM 作为执行路径的中心组件，从而同时提升效率、降低资源需求，而不牺牲任务成功率。

## 2. 论文提出的方法论

### 核心思想
- 独立编码视觉观测与语言指令，通过**轻量级双向视觉-语言交互**直接融合信息，再用**紧凑解码器**以单次前向传播预测连续动作块，彻底绕开 LLM 中心化的表示空间。
- 核心公式化对比：
  - 传统：`eZvn = Pv(Ev(On))`, `HLn = FL([eZvn; Tok(x)])`，动作从 LLM 输出表示中解码；
  - TurboVLA：直接用 `Zvl_n = [V^N_n; L^N_n]` 输入动作解码器，无需 LLM 中间层。

### 模型架构（三部分）

**(1) 多模态特征编码（Multimodal Feature Encoding）**
- 视觉编码器：使用 **DINOv3**（ViT-B / ViT-L），提取空间视觉特征，并加入位置编码与相机视角编码；
- 文本编码器：使用轻量级 **BERT**（T5-small、SigLIP 也可替代），保留完整 token 序列（而非池化向量），以保留对象、属性、空间关系等细粒度语义；
- 机器人状态：由轻量投影网络 f_state 编码，直接送入动作解码器，不参与跨模态交互，保持交互模块聚焦于任务条件场景理解。

**(2) 视觉-语言交互模块（Vision-Language Interaction Module）**
- 采用 **N=6 层双向交叉注意力**（双向 cross-attention），包括：
  - Visual-to-Instruction 注意力：注入场景上下文，更新指令特征；
  - Instruction-to-Visual 注意力：以任务语义调制视觉特征；
- 每层由 LayerNorm、双向交叉注意力、模态专用 FFN 和残差连接构成；
- 初始权重来自 Grounding DINO 的 grounding-pretrained 特征增强权重；
- 最终将更新后的两路特征拼接，得到动作可用的多模态表示 `Zvl_n`。

**(3) 连续动作块预测（Continuous Action Chunk Prediction）**
- 采用 **ACT 风格**的轻量 Transformer 解码器；
- 输入：H 个可学习动作查询 `Q_a` + 融合多模态特征 `Zvl_n` + 机器人状态 `Zsn`；
- 输出：`A_hat_n ∈ R^{H×d_a}`，即 **H 步动作块一次性并行解码**，无自回归 token 生成；
- 训练目标：行为克隆，仅使用 **ℓ1 loss**，无需任何辅助语言建模损失。

## 6. 论文的主要结论与发现

1. **LLM 不是执行级控制的必要条件**：TurboVLA 以 0.2B 参数、31.2 ms 延迟、0.9 GB VRAM 实现 97.7% LIBERO 平均成功率，匹配甚至超越 π0.5（3.4B 参数、93.6 ms、96.9%）等大规模 VLA，证明执行级操作不必然需要 LLM 作为中心接口。
2. **架构选择比单纯优化动作生成更有效**：对比 OpenVLA-OFT、DDVLA 等仅优化动作解码但仍保留 LLM 的方法，TurboVLA 速度更快且成功率更高，说明瓶颈在于 LLM 本身而非动作生成机制。
3. **跨场景泛化与实用性**：在双臂仿真（RoboTwin 2.0）达到 60.2% 平均成功率、43.4 ms 延迟，优于 π0.5（57.0%、95.6 ms）和 StarVLA-α（50.3%、74.9 ms）；在真实世界 4 个任务中成功率全面优于 π0.5。
4. **消融验证了各组件必要性**：
   - 无语言条件时成功率骤降至 70.8%（Goal 套件几乎崩溃：11.6%），证明语义指令的必要性；
   - 双向交互（97.7%）优于单向交互（96.1%/96.5%）和无交互（95.2%）；
   - N=6 交互深度与 H=12 动作视界为最佳配置。

- **架构创新性**：提出 `V+L→A` 新范式，从根本上绕开 LLM 中心化瓶颈，视角新颖，打破了 VLA 必须“大模型驱动”的惯性思维；

## 8. 不足与局限

- **语义理解与推理能力有限**：TurboVLA 主要针对执行级指令设计，无法处理开放式的语言生成、复杂任务分解、多步规划和抽象推理。对于需要高层语义理解的任务（如“整理房间”、“根据菜谱做饭”），其能力明显不足；

- **训练时长未报告**：虽然提供了训练步数、batch size 等细节，但未给出训练总时长，难以评估训练成本；

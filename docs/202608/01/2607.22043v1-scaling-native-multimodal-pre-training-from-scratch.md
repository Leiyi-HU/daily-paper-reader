## 摘要
尽管大型语言模型（LLMs）展现出卓越的推理能力，但其依赖纯文本预训练限制了对多模态物理世界的感知。原生多模态预训练通过从头开始在多模态输入上训练模型来避免这一限制，从而实现深度的跨模态整合，并缓解传统后期融合架构固有的优化不对称性。尽管有这些优势，这一范式的扩展特性尚未得到系统性表征。为弥补这一空白，我们在固定计算预算下研究了训练基于Transformer的视觉-语言模型时的最优模型大小和标记数量。我们证明，最小目标损失遵循可预测的计算法则，而计算最优的模型大小和标记数量按幂律扩展。值得注意的是，语言和多模态目标表现出不同的扩展行为。语言分配法则在很大程度上不受数据组成的影响，表明无论多模态数据比例如何，语言学习都是稳定的。相反，多模态分配法则对这种组成高度敏感。具体而言，以文本为主的数据混合仅在更大的模型规模下才变得计算高效，从而将最优资源分配转向更大的模型容量。此外，通过对数据组成对计算法则和分配指数的影响进行建模，我们推导出一个效率前沿面，指定了模型大小、标记数量和数据混合的精确配置。下游评估进一步揭示，原生多模态预训练会诱发正向的跨模态迁移，从而增强纯文本空间推理并实现稳健的多模态上下文学习。总之，这项实证研究为可预测地扩展多模态基础模型奠定了必要的基础。

## Abstract
Although large language models (LLMs) exhibit remarkable reasoning capabilities, their reliance on text-only pre-training restricts the perception of the multimodal physical world. Native multimodal pre-training avoids this limitation by training models from scratch on multimodal inputs, thereby achieving deep cross-modal integration and mitigating optimization asymmetries inherent to traditional late-fusion architectures. Despite these advantages, the scaling properties of this paradigm remain systematically uncharacterized. To address this gap, we investigate the optimal model size and token count for training a transformer-based vision-language model under a fixed computational budget. We demonstrate that minimal objective loss adheres to a predictable compute law, whereas compute-optimal model sizes and token counts scale as power laws. Notably, language and multimodal objectives manifest distinct scaling behaviors. The language allocation law is largely invariant to the composition of the data, indicating stable language learning regardless of the multimodal data ratio. Conversely, the multimodal allocation law is highly sensitive to this composition. Specifically, text-heavy mixtures become compute-efficient only at larger model scales, shifting the optimal resource allocation toward greater model capacity. Additionally, by modeling the influence of data composition on compute laws and allocation exponents, we derive an efficiency frontier specifying precise configurations of model size, token count, and data mixture. Downstream evaluations further reveal that native multimodal pre-training induces positive cross-modal transfer, thereby enhancing pure-text spatial reasoning and enabling robust multimodal in-context learning. In summary, this empirical research establishes the essential groundwork for predictably scaling multimodal foundation models.

## 二、方法论：核心思想、关键技术细节与公式

**核心思想：**
将联合预训练目标解耦为独立的语言目标（L_text）和多模态目标（L_mm），分别分析两者在各自有效计算预算下的最优资源分配规律，再通过联合 Pareto 前沿统一权衡。

**关键技术细节与公式：**

1. **计算最优分配框架：**
   - 采用标准近似 C = 6ND，计算预算由模型规模 N 与训练 token 数 D 严格决定。
   - 优化目标：在固定计算约束下最小化损失 L(N,D)。

2. **有效计算分解：**
   - 根据数据组成定义各目标的"有效计算"：C_text = 6ND_text，C_mm = 6ND_mm，其中 D_text = D/(1+r)，D_mm = Dr/(1+r)，r 为多模态数据比例。
   - 最优分配遵循幂律关系：N_opt(C) ∝ C^a，D_opt(C) ∝ C^b，且 a + b = 1。

3. **两种互补的估计方法：**
   - **IsoFLOP 轮廓法（主要估计器）**：在固定预算 C 下，绘制各模型规模的损失曲线，用抛物线拟合，最小值处即为最优模型规模 N_opt(C)，进而推导 D_opt(C)。
   - **训练曲线包络法（交叉验证）**：汇集所有规模模型的训练轨迹，提取损失对计算量的下包络，每个包络点对应特定 (N,D) 配置，独立回归分配指数。

4. **计算前沿函数：**
   L(C) = E + (C_c/C)^β
   其中 E 为不可约损失下限，C_c 为临界计算规模，β 为衰减指数，通过最小二乘对数空间拟合。

5. **联合 Pareto 前沿的对称性建模：**
   - 语言目标建模为**组成不变（composition-invariant）**（不受 r 影响）；
   - 多模态目标建模为**组成可变（composition-variant）**（随 r 变化）；
   - 该不对称反映了模态间的结构差异：文本语言建模依赖自足的统计结构，视觉 token 主要提供外部上下文，不改变 token 间依赖。

6. **模型架构：**
   - 基于 MoE（混合专家）架构的 decoder-only Transformer；
   - 不使用传统视觉编码器，仅用单个 patch embedding 层将图像直接映射为连续 patch embedding；
   - 采用无辅助损失的 MoE 训练方法；
   - 训练损失仅计算文本 token，视觉 token 被 mask。

## 六、主要结论与发现

1. **语言目标扩展规律 — 组成不变性**：计算最优分配在很大程度上不受数据组成影响。引入多模态 token 不改变为最小化语言损失所需的最优参数量。两种估计器未显示同步下降趋势，说明微小的指数偏移属于拟合误差噪声。

2. **多模态目标扩展规律 — 组成敏感性**：当 r 从 0.1 增至 0.3 时，最优模型规模指数显著下降（IsoFLOP：a 从约 0.71 降至约 0.64），跨模态对齐呈"数据饥饿"特征。多模态数据越密集，最优分配越偏向数据扩展而非参数扩展。

3. **联合 Pareto 前沿**：语言-多模态之间存在严格的 Pareto 权衡前沿。低多模态比例（r=0.1）时最优参数扩展指数为 N_opt ∝ C^0.69；r=0.3 时降至 C^0.66，同时 token 扩展指数增至 C^0.34。扩展统一多模态模型需要"以更大的 token 预算换取受限的参数扩张"。

4. **跨模态正迁移**：多模态预训练显著提升纯文本抽象空间推理（SpatialEval 的 MazeNav 和 SpatialMap 子任务），且优势随模型规模扩大而增大。

5. **多模态上下文学习涌现**：
   - 小模型（71M-340M）few-shot 模板基本无增益，A3B 模型 3-shot 增益达 +2.43 个百分点；
   - 上下文学习随训练数据量增加而逐渐获得，A874M 和 A3B 模型在训练后期才出现明显 shot 间差异；
   - few-shot 增益主要集中在空间推理任务上，OCR/识别类任务上无增益甚至略有下降。

6. **语言能力保持**：引入多模态数据后，16 个文本基准的平均准确率在各模型规模上偏差小于 1 个百分点，核心语言能力不受损害。

## 七、优点

1. **开创性研究问题**：首次系统性地从计算最优角度研究原生多模态预训练的扩展规律，填补了该范式在 scaling law 层面的空白。

2. **方法严谨性**：采用 IsoFLOP 轮廓和训练曲线包络两种独立估计方法交叉验证，显著增强了结论的可靠性，排除了特定拟合形式带来的伪影风险。

3. **目标解耦策略**：将联合目标解耦为语言和多模态两个子目标，分别分析其扩展行为，揭示了两者本质不同的扩展规律——这一视角是此前研究（如将目标建模为单一聚合损失）所不具备的。

4. **Pareto 前沿建模**：量化了数据混合比例对最优配置的影响，推导出可操作的语言-多模态效率前沿，直接指导实际训练部署中的资源分配决策。

5. **下游验证充分**：用 16+23 个基准全面评估了模型能力，不仅验证了扩展规律的正确性，还发现了跨模态迁移和上下文学习涌现等重要现象。

6. **架构选择具有代表性**：采用无视觉编码器的 decoder-only MoE 架构，代表原生多模态预训练的前沿方向，结论具有前瞻性。

## 八、不足与局限

1. **模型规模有限**：最大激活参数仅 3B，属于中等规模。扩展规律的外推至更大规模（如 10B、100B 级别）尚未经验证，幂律外推存在不确定性。

2. **数据多样性不足**：仅使用单一图像-文本数据族，未覆盖视频、音频等其他模态；数据混合比例变化范围有限（r=0.1 至 0.3），极端比例下的行为未知。

3. **损失代理的局限**：仅以训练损失作为评估指标，虽因 token 基本只被过一次而具合理性，但损失下降与实际任务性能提升之间并非严格等价。

4. **缺乏横向对比**：未与其他原生多模态训练方法（如 Shukor et al. 早期基于聚合损失的扩展研究）进行直接的实证对比，无法量化本方法相比已有工作的增益。

5. **泛化性问题**：结论基于特定架构（MoE decoder-only）、特定优化器（Muon）和特定数据分布，是否适用于密集架构或其他训练配置尚不明确。

6. **上下文长度限制**：4K 上下文限制导致评估时需压缩图像 token，可能低估了模型在高分辨率图像理解上的真实能力。

7. **评估精度问题**：部分开放任务采用精确匹配（exact-match）评价，对生成式任务的评估可能过于严苛，无法全面反映模型能力。

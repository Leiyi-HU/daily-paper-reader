## 摘要
具身智能日益依赖由预训练视觉-语言模型构建的可查询语义地图，以实现零样本物体目标导航（ObjectNav）。然而，现有方法通常依赖纯文本查询，随着语义特定性向细粒度物体类别增强，其可靠性会下降。我们提出IMPRINT，一种零样本即插即用框架，通过引入网络来源图像来丰富文本物体查询，以提升在可查询地图中的接地性。检索到的图像使用视觉-语言模型编码，与语义地图匹配以生成相似度图，并聚合以产生上下文感知的定位。值得注意的是，这无需训练或修改底层导航策略。为明确评估长尾行为，我们提出了HSSD-rare，一个基于Habitat合成场景构建的新ObjectNav基准，具有语义特定的子类别。在OVON和HSSD-rare上，图像条件查询均一致地改善物体接地性，并带来端到端的导航增益。进一步分析表明，将定位增益转化为导航性能关键取决于下游检测质量，这突显了长尾具身导航中的一个关键系统瓶颈。

## Abstract
Embodied AI increasingly relies on queryable semantic maps built from pre-trained vision-language models to enable zero-shot Object Goal Navigation (ObjectNav). However, existing approaches typically depend on text-only queries, which become less reliable as semantic specificity increases toward fine-grained object categories. We introduce IMPRINT, a zero-shot plug-and-play framework that enriches textual object queries with web-sourced images to improve grounding in queryable maps. Retrieved images are encoded using a vision-language model, matched against the semantic map to produce similarity maps, and aggregated to yield context-aware localization. Notably, this requires no training or modification of the underlying navigation policy. To explicitly evaluate long-tail behavior, we present HSSD-rare, a new ObjectNav benchmark built on Habitat Synthetic Scenes and featuring semantically specific subcategories. Across both OVON and HSSD-rare, image-conditioned queries consistently improve object grounding and yield end-to-end navigation gains. Further analysis reveals that translating localization gains to navigation performance depends critically on downstream detection quality, highlighting a key systems bottleneck in long-tail embodied navigation.

## 2. 论文提出的方法论：核心思想与关键技术细节

- **核心思想**：受人类搜索行为启发（遇到不熟悉的物体会先查图），IMPRINT将纯文本查询替换为"文本+网络检索图像"的多模态查询，实现零样本、无需训练、不修改导航策略的目标定位增强。
- **模型无关与即插即用**：IMPRINT不改变底层导航策略（如VLFM、OneMap的探索/决策逻辑），仅替换查询注入方式；对任意可查询语义地图架构通用。
- **Web图像检索**：
  - 针对查询文本，检索top-n候选图像（n通过消融确定，默认范围5–15）。
  - 长尾类别检索时，在查询前附加头部类别（如"chair, Upholstered Drop Chair"）以提升检索质量。
  - 元数据门控：仅当ALT文本或URL路径中出现头部名词时保留图像；同时去除重复图像。
  - 检索图像本地缓存，平均延迟约0.61±0.16秒/张。
- **语义地图构建与查询**：
  - 沿用VLFM的映射管线：RGB经视觉-语言编码器编码得嵌入，深度图经相机内参和位姿投影到2D网格；多次观测取平均聚合。
  - 全局特征编码器（如BLIP2）用整图嵌入写入对应可见区域；patch级编码器（如SED）则逐patch投影至各自空间足迹，实现更细粒度的cell级语义赋值。

## 6. 论文的主要结论与发现

- **图像条件查询一致改善语义接地**：静态阶段在OVON-syn（+10.54 SR，−1.05m DTG）和HSSD-rare（+6.37 SR，−1.19m DTG）均获得显著提升；语义粒度越细，提升幅度越大（seen: +1.01 → unseen: +3.39 → synonyms: +3.87 SR）。
- **接地提升向端到端导航的迁移有条件性**：在一般类别的OVON-syn上，图像条件查询稳定转化为导航收益（如VLFM SR从23.83→27.17）；在长尾的HSSD-rare上提升更温和，提示瓶颈不在语义接地本身。
- **物体检测是长尾导航的关键系统瓶颈**：失败分析显示Timeout占主导（55.3%），且其中仅4%的episode进入目标2m范围内，属于大尺度语义遗漏而非近目标控制误差；Mis-detection占29.8%。当用top-3参考图像增强YOLOWorld检测器后，OneMap在OVON-syn上SR从13.00提升至18.17、在HSSD-rare上从7.05提升至11.75，SPL同步大幅增长——证实检测模块是限制定位增益传导的核心环节。
- **算术平均是最优的相似度图聚合策略**，优于调和平均和混合策略（调和均值严重劣化性能）。
- **图像数量存在最优区间**：OVON-syn峰值为n=10，HSSD-rare峰值为n=15，长尾目标需要更多视觉证据；继续增加收益递减且引入噪声。
- **不同编码器行为差异**：SED在一般粗粒度上定位最强（patch级语义的优势），但长尾条件下提升幅度收窄；BLIP2和SigLIP在两种分布下保持稳定改善。
- **实时可行性**：真实世界5个episode中，文本查询仅成功1个，图像增强成功4个（唯失败项为极小尺寸物体），证明部署可行性。

## 7. 优点

- **即插即用、零训练范式**：不修改导航策略或检测器，仅替换查询嵌入方式，对现有基于可查询地图的ObjectNav系统可即时代入使用。
- **清晰的因果解耦设计**：静态/在线两阶段将"定位质量"和"导航执行"分离，使实验分析能精确定位性能瓶颈到底在哪个模块。
- **受控干预实验方法论**：不用"加更多模块"来模糊论断，而是专门增强检测器来验证瓶颈假设，实验设计有归因力度。
- **自建基准严谨**：HSSD-rare不仅提供episode，还含OOV率统计（41.68%）和LLM稀有度评分分布（1–5级），从两个维度量化"长尾性"而非仅宣称细粒度。
- **消融充分覆盖关键维度**：聚合策略、图像数量、分割差异均有系统消融；真实世界实验虽小，但提供了从仿真到部署的生态闭环。
- **模型无关性验证**：横跨holistic（BLIP2、SigLIP）和patch级（SED）特征，以及三类策略结构（地图+PointGoal的两类，直接策略条件化的ZSON），增强了结论普适性。

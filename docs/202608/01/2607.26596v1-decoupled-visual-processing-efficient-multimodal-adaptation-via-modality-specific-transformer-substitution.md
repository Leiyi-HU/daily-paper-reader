## 摘要
多模态大语言模型（MLLMs）通过将视觉和文本理解整合到统一的Transformer架构中，展现了卓越的能力。然而，为了进行视觉指令微调而微调这些模型的所有参数在计算上是昂贵的，且往往不必要，因为视觉和文本标记在网络的更深层中对表示的需求存在显著差异。在本文中，我们提出了解耦视觉处理（DVP），一种高效的训练框架，它将预训练LLM的上层解码器层替换为一个轻量级、可独立训练的单一Transformer块，专门用于视觉标记处理。具体来说，在通过解码器层的前半部分进行共享处理之后，视觉和文本标记被拆分：视觉标记通过一个新初始化的单一Transformer块进行路由，而文本标记则继续通过原始的冻结解码器层。然后，在语言建模头之前将两个流拼接起来。在训练期间，仅更新该单一Transformer块，从而大幅减少可训练参数的数量。在LLaVA-1.5框架上的实验表明，DVP在MME、POPE和ChartQA基准上取得了具有竞争力的性能，同时仅训练总参数的一小部分，这表明MLLMs中的视觉表示可以通过解耦的、参数高效的路径得到有效学习。

## Abstract
Multimodal large language models (MLLMs) have demonstrated remarkable capabilities by integrating visual and textual understanding within a unified transformer architecture. However, fine-tuning all parameters of these models for visual instruction tuning is computationally expensive and often unnecessary, as the representation requirements for visual and textual tokens diverge significantly in the deeper layers of the network. In this paper, we propose Decoupled Visual Processing (DVP), an efficient training framework that replaces the upper decoder layers of a pretrained LLM with a lightweight, independently trainable single transformer block dedicated exclusively to visual token processing. Specifically, after shared processing through the first half of the decoder layers, visual and textual tokens are split: visual tokens are routed through a newly initialized single transformer block while textual tokens continue through the original frozen decoder layers. The two streams are then concatenated before the language modeling head. During training, only the single transformer block is updated, dramatically reducing the number of trainable parameters. Experiments on the LLaVA-1.5 framework demonstrate that DVP achieves competitive performance on MME, POPE, and ChartQA benchmarks while training only a fraction of the total parameters, suggesting that visual representations in MLLMs can be effectively learned through a decoupled, parameter-efficient pathway.

### 方法：核心思想、关键技术细节与算法流程

#### 核心思想
- 将解码器分层为两部分：前 \(K\) 层为共享层（两种模态共同处理，实现跨模态对齐）；后 \(L-K\) 层为解耦层（视觉与文本分流处理）。
- 视觉 token 仅经过**一个新初始化的单一 Transformer 块**，文本 token 继续通过**原始的冻结解码器层**。
- 训练时**仅更新该单一 Transformer 块**，原始 LLM 全部参数冻结，实现极度参数高效。

#### 关键流程（四阶段）
1. **共享处理（Phase 1）**：全部 token 共同通过前 \(K\) 层解码器：
   \[
   X^{(K)} = \text{DecoderLayer}_{K-1} \circ \cdots \circ \text{DecoderLayer}_0 (X^{(0)})
   \]
   该阶段实现视觉-文本之间的跨模态注意力与上下文对齐。
2. **模态拆分（Phase 2）**：按模态将隐藏状态切分为 \(X_v^{(K)}\)（视觉）与 \(X_t^{(K)}\)（文本）。
3. **解耦处理（Phase 3）**：
   - 视觉路径：\(\hat{X}_v = \text{SingleTransformer}(X_v^{(K)})\)，由新初始化的单 Transformer 块处理；
   - 文本路径：\(\hat{X}_t = \text{DecoderLayer}_{L-1} \circ \cdots \circ \text{DecoderLayer}_K (X_t^{(K)})\)，沿用冻结的原始层。
4. **拼接与预测（Phase 4）**：将两条路径的输出拼接，送入 LM Head：
   \[
   Y = \text{LM\_Head}([\hat{X}_v; \hat{X}_t])
   \]
   训练目标为标准自回归语言建模损失（仅计算文本 token 上的损失）。

#### 设计选择
- **拆分点**：Vicuna-7B 共 32 层，取 \(K=17\)（即第 16 层后拆分），近似均分解码器。
- **单块压缩**：用一个 Transformer 块替换视觉路径上的 15 层解码器（层 17\~31），强迫模型学习紧凑映射，验证了视觉处理中的冗余性。
- **完全冻结原 LLM**：保证预训练语言能力不退化，可训练参数约为被替换层参数的 \(1/(L-K)\)（本配置约为 1/15）。

### 主要结论与发现

1. **视觉 token 不需要完整解码器深度**：单一 Transformer 块替代 15 层解码器（处理视觉 token）后，模型仍能保持与全量微调相当的性能，说明原架构在视觉处理上存在显著冗余。
2. **参数效率极高**：仅训练约 3.1% 的总参数（约 0.2B），即可在 MME 感知（1440 vs. 1496）、POPE（0.8619 vs. 0.8577，反超）上逼近或超越全量微调基线。
3. **解耦可减少幻觉**：POPE 上 DVP 表现最佳，提示视觉路径不受文本偏向上层加工的影响，有助于抑制对象幻觉。
4. **冻结参数起隐式正则作用**：Normal Training（拆分+全量训练）在感知上显著更差（1225），表明不加约束的全量训练可能破坏预训练视觉能力；冻结 LLM 权重视为一种正则化手段。
5. **跨模态对齐主要发生在低层**：17 层共享处理足以支撑视觉信息的"自足"表征，高层跨模态迭代交互并非必需（但 ChartQA 类任务除外）。
6. **架构不对称性合理**：文本路径需要更深加工以支撑生成，而视觉路径主要为条件信号，单块处理已足够。

- 思想简洁且洞察深刻：基于"低层对齐、高层特化"的表示学习直觉，提出明确的架构分离假设。

## 摘要
标准视觉语言模型（VLM）存在莫拉韦克悖论：它们在复杂的离线视觉推理方面表现出色，但在简单的流式感知任务上却表现不佳且处理效率低下。我们提出了Mage-VL，一种高效的编解码器原生流式基础模型，用于实时多模态理解和交互。其核心是我们的自定义分词器Mage-ViT，它不再进行均匀帧采样，而是利用运动向量和残差能量，在稀疏锚点（I）帧和预测（P）帧之间选择性地编码动态、高熵区域。在16x16块级别上操作，这使得视觉token消耗减少了75%以上，同时保留了时空上下文。Mage-ViT在大约5.6亿张无标签图像和1亿个无标签视频帧上从头训练，其表现可与在数十亿图像-文本对上训练的旗舰编码器相媲美或更优。我们建立了AI4AI数据流水线，包括用于多模态字幕生成的提示-代码联合优化以及用于指导训练方案的AI驱动性能诊断。此外，通过一种受生物启发的双系统架构——一个轻量级的系统1事件门和一个因果系统2解码器——Mage-VL实现了主动式流式感知。大量评估表明，Mage-VL-4B在静态任务上与Qwen3-VL-4B相当，同时在视频理解和2D/3D空间推理方面取得了显著提升，墙钟推理速度最高提升3.5倍，并全面超越了150亿参数的Phi-4推理视觉基线。除了模型产物之外，我们还提供了七项关键实证发现，涵盖预训练数据效率、可变分辨率缩放、编解码器系统加速、VideoQA SFT冗余、运动-空间协同、AI4AI数据流水线以及用于多模态RL的Zero-Vision SFT。

## Abstract
Standard vision-language models (VLMs) suffer from Moravec's paradox: they excel at complex offline visual reasoning but struggle with simple streaming perception tasks and process them inefficiently. We present Mage-VL, an efficient codec-native streaming foundation model for real-time multimodal understanding and interaction. At its core, our custom tokenizer, Mage-ViT, replaces uniform frame sampling by selectively encoding dynamic, entropy-rich regions using motion vectors and residual energy across sparse anchor (I) and predicted (P) frames. Operating at a 16 x 16 patch level, this reduces visual token consumption by over 75% while preserving spatiotemporal context. Trained from scratch on approximately 560M unlabeled images and 100M unlabeled video frames, Mage-ViT matches or outperforms flagship encoders trained on billions of image-text pairs. We establish AI4AI data pipelines encompassing prompt-code joint optimization for multimodal captioning and AI-driven performance diagnosis to guide training recipes. Furthermore, through a bio-inspired dual-system architecture - a lightweight System 1 event gate and a causal System 2 decoder - Mage-VL enables proactive streaming perception. Extensive evaluations show that Mage-VL-4B matches Qwen3-VL-4B on static tasks while achieving strong gains in video understanding and 2D/3D spatial reasoning, with up to a 3.5x wall-clock inference speedup, and comprehensively surpasses the 15B Phi-4-reasoning-vision baseline. Beyond model artifacts, we deliver seven key empirical findings covering pre-training data efficiency, variable-resolution scaling, codec system acceleration, VideoQA SFT redundancy, motion-spatial synergy, AI4AI data pipelines, and Zero-Vision SFT for multimodal RL.

**问题根源**：
- 主流 VLM 依赖在网页级静态图像上预训练的视觉编码器（如 SigLIP2 在超 100 亿图像-文本对上训练），与连续视觉输入存在结构性错配。
- 视频处理通常采用固定分辨率的均匀帧采样，无视时空冗余，静态背景区域被反复编码。
- 生物视觉系统则通过前端过滤冗余、优先处理动态信息，并采用快慢双系统协同工作，而现有 VLM 架构缺乏这种设计。

**研究意义**：本文提出 Mage-VL，一个编解码器原生（Codec-Native）的流式多模态基础模型，实现实时多模态理解和交互，为高效流式感知提供了全新范式。

## 2. 方法论：核心思想、关键技术细节

### 2.1 Mage-ViT 视觉编码器

**核心思想**：借鉴视频编解码器原理，按信息密度分配视觉 token，而非均匀采样。

**关键技术细节**：

- **Codec-driven patchifier（编解码器驱动分块器）**：
  - 将输入划分为 16×16 像素块，估计每个时空 patch 的重要性张量 S ∈ R^T×H×W。
  - 默认使用 HEVC/H.265 传统编解码器，S = 运动向量幅值 + P 帧残差能量的加权组合。
  - 支持神经编解码器（如 DCVC-RT），此时 S 直接取自学习概率模型的负对数似然（比特分配映射）。
  - I 帧（锚定帧）全量保留；P 帧（预测帧）仅保留按重要性 S 选取的 top-k patches。
  - 64 帧片段、每帧 16×16 tokens 时，token 预算 B=4096，约减少 75% token。

- **ViT 主干**：24 层 pre-norm ViT，隐藏维度 1024，16 注意力头，GELU MLP（4× 扩展），使用 Flash Attention 2。

- **共享 3D 旋转位置编码**：在未剪枝的时空网格上编码，即使大量网格被丢弃仍保留时空关系。

**预训练流程**：
- **Stage 1（可变分辨率图像预训练）**：分辨率 224–448，宽高比 1:2 到 2:1，使用负采样聚类判别目标。
- **Stage 2（图像+视频联合预训练）**：视频 256 分辨率、64 帧/片段、token 预算 4096；三种 patchification 模式混合（50% codec、40% chunk-wise、10% collage）。

**数据规模**：约 5.6 亿张无标签图像 + 1 亿个无标签视频帧。

### 2.2 Mage-VL 统一架构

**三大组件**：
1. **Codec-native 视觉编码器（Mage-ViT）**：统一处理图像、视频和流式输入。
2. **视觉-语言投影器**：轻量两层 MLP，映射到语言模型 token 嵌入空间。
3. **因果语言解码器**：基于 Qwen3-4B-Instruct-2507 初始化，统一处理图像、短视频、长视频和超长视频。

**主动式流式机制（双系统架构）**：
- **System 1（轻量事件门）**：持续评估传入的 codec 窗口视觉特征 h_t，预测 p_speak = g(h_t)，当 p_speak ≥ τ 时触发响应。
- **System 2（因果解码器）**：门打开时，使用最近 N 个 codec 视觉段的局部滑动窗口执行标准自回归响应生成。

### 2.3 五阶段渐进训练课程

### 2.4 AI4AI 数据管道

- **图像描述提示词优化**：Github Copilot 作为 prompt 修改器 + GPT-5 作为评分裁判（完整性、冗余性、连贯性、OCR 保真度四维评估），经 10 轮迭代优化。

## 6. 主要结论与发现

**核心结论**：Mage-VL-4B 在静态任务上与 Qwen3-VL-4B 相当，在视频理解和 2D/3D 空间推理上显著领先，推理速度最高提升 3.5 倍，并全面超越 15B 参数的 Phi-4-reasoning-vision。

**七项关键实证发现**：

1. **Web 规模预训练并非必需**：Mage-ViT 仅用 5.6 亿图像 + 1 亿视频帧即可与 SigLIP2 等数十亿图像-文本对训练的编码器匹敌。

2. **可变分辨率预训练实现单调缩放**：Mage-ViT 性能随 token 预算单调提升，而固定分辨率基线在高分辨率下退化。

3. **编解码器原生分词显著提升视频效率**：在相同 token 预算下准确率更高，最高 3.5× 墙钟加速；低-中预算区间优势最大（绿色阴影区域）。

4. **稠密视频描述可替代长 VideoQA SFT**：仅用稠密视频描述 + 短视频 SFT 即可实现强零样本长 VideoQA 能力。

5. **动态视频训练增强静态空间智能**：2D/3D 空间推理（CV-Bench-3D、EmbSpatial、CrossPoint）显著受益于视频训练。

6. **AI4AI 数据管道提升下游性能**：提示词优化带来 InfoVQA +5.62、OCRBench +3.80 等一致增益；代码-提示协同设计解决时间戳定位瓶颈。

7. **Zero-Vision SFT 释放多模态 RL 潜力**：跳过视觉 SFT 直接采用纯文本推理 SFT + RL 可在 24 个基准上平均提升 +5.33%，RL 收敛步骤减少 50.7%。

**跨 codec 鲁棒性**：传统 HEVC 与神经 DCVC-RT 选择器在推理时性能几乎一致（平均 58.0 vs 57.7），验证了"时间可预测性"作为 token 分配的可迁移准则。

## 7. 优点

### 方法层面
- **创新性强的编解码器原生设计**：将视频编解码原理引入 VLM 视觉 tokenizer，从源头减少时空冗余，区别于后压缩/后选择的既有方案。
- **数据高效性**：证明从零预训练的小规模编码器可匹敌数十亿级预训练编码器，挑战了传统缩放信念。
- **统一架构**：单模型同时支持图像、离线视频、流式交互，无需特定模态解码器。
- **双系统设计启发**：受生物视觉启发的 System 1 事件门 + System 2 因果解码器，天然适配流式场景。
- **跨 codec 家族鲁棒性**：与具体 codec 机制解耦，仅依赖"时间可预测性"这一通用准则，泛化性强。
- **AI4AI 实践先行**：在六个月内率先实现提示词-代码协同优化的闭环数据管道，具有方法论价值。

### 实验层面
- 使用 lmms-eval 官方模板，无模型特定提示词调优或人工修正。
- 与 Qwen3-VL 共享 LLM 骨干（4B Qwen3），构成良好对照实验（仅视觉前端不同）。
- matched-budget 协议（tc-N vs frame-N）确保对比公平性。
- 报告完整墙钟时间（包含视频加载），而非仅报告模型前向时间。

### 开源贡献
- 开源 Mage-ViT 和 Mage-VL-4B 模型权重、代码和项目页面，附录提供完整优化的系统提示词（可复现）。

## 8. 不足与局限

### 实验与评估局限
- **Agentic 和数学推理能力不足**：作者明确承认在复杂 agentic 工作流和数学推理上弱于 Qwen3-VL，归因于文本数据短缺和未做 RL 后训练。
- **部分基准落后**：MV-Bench、TempCompass、MMVU 等依赖稠密逐帧外观的基准上落后于 Qwen3-VL。
- **严格单变量消融缺失**：视频训练与空间智能提升之间的因果链未能通过严格消融验证（作者自认）。
- **流式基线对比条件不完全一致**：如 StreamMind 在 SoccerNet-Caption 上做过分布内训练，而 Mage-VL 未针对该域优化；JoyAI 评估容差不同。
- **Zero-Vision SFT 实验独立于主模型**：使用 LLaVA-OV-1.5 Quick Start 数据在开源管道上验证，并未直接应用于 Mage-VL 主模型本身。

### 效率评估局限
- 墙钟时间对比中 Qwen3-VL 的时间未包含估计的视频加载时间（1.01N/8 和 1.01N），可能高估了 Mage-VL 的实际加速优势。
- 效率分析在单节点上执行，未报告多节点或不同硬件条件下的泛化。

### 数据处理局限
- 稠密描述源自教师模型（Qwen3-VL-32B、GPT-4.1 等），存在教师偏差放大风险。
- 视频描述的时间戳标注来源于自动管道，可能存在错误传播。

### 部署限制
- 流式触发依赖于固定阈值 τ，未讨论自适应阈值或校准策略在不同场景下的鲁棒性。
- 4B 参数规模虽轻量，但实时流式部署的端侧/边缘场景可行性未充分讨论。
- 未涉及音频-视觉融合，限制了真实场景中的完整多模态流式交互能力。

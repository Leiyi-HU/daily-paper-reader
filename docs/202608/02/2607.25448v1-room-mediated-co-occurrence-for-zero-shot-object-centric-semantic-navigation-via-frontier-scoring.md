## 摘要
零样本ObjectNav方法越来越多地使用视觉-语言先验，但潜空间中直接的物体-物体相似度往往是空间共现的弱代理。我们提出了一种分析性、无需训练的语义导航流水线，通过紧凑的房间词典来中介物体关系。每个物体标签被映射到CLIP导出的房间概率向量（RPV），物体-目标共现由RPV分布重叠计算。这些分数通过测地线洪水填充传播（快速行进法）投影到值图上，并具有自适应信号衰减，并用于对导航的前沿进行语义分数排序。这些组件共同构成一个集成的、无需训练的、以物体为中心的开放词汇零样本导航流水线。结果表明，与HM3D数据集验证集上的图像整体基线相比，我们以物体为中心的方法在成功率（SR）和按加权逆路径长度（SPL）的成功率上分别相对提高了3%和1.3%，同时保持了可解释性和开放词汇灵活性。代码可在：uts-ri.github.io/RPV-SemNav获取。

## Abstract
Zero-shot ObjectNav methods increasingly use vision-language priors, but direct object-object similarity in the latent space is often a weak proxy for spatial co-occurrence. We present an analytical, training-free semantic navigation pipeline that mediates object relationships through a compact room lexicon. Each object label is mapped to a CLIP-derived Room Probability Vector (RPV), and object-target co-occurrence is computed from RPV distribution overlap. These scores are projected onto a value map using geodesic flood-fill propagation (Fast Marching Method), with adaptive signal decay, and are used to rank frontiers by semantic score for navigation. Together, these components form an integrated, training-free, object-centric pipeline for open-vocabulary zero-shot navigation. Results show that our object-centric approach improves Success Rate (SR) and Success by weighted inverse Path Length (SPL) by a relative 3% and 1.3%, respectively, compared to image-holistic baselines on the HM3D dataset validation split, while preserving interpretability and open-vocabulary flexibility. Code is available at: uts-ri.github.io/RPV-SemNav.

## 1. 核心问题与整体含义（研究动机与背景）

- **任务背景**：ObjectNav（Object-Goal Navigation）要求智能体在未知环境中通过探索定位指定物体，是通用机器人导航的基础能力。几何感知提供拓扑约束（哪里能走），语义感知则提供搜索先验（该往哪儿找）。
- **核心问题**：现有零样本方法多依赖视觉-语言模型（VLM），但 **在潜空间中直接使用物体-物体嵌入相似度作为空间共现的代理，往往不可靠**——语言/视觉相似的物体在嵌入空间中距离近，但在物理空间中可能完全不相关（例如"电视"和"遥控器"在语义上近，但"浴室"里的物体和"卧室"里的物体可能语言上相似却空间无关）。
- **解决思路**：通过一个**紧凑的房间词典**（room lexicon）作为中间语义空间，将物体关系"调节"为空间关系——即：物体之间是否共现，取决于它们是否倾向于出现在同一类房间中。据此构建了：
  - 零样本（zero-shot）
  - 免训练（training-free）
  - 开放词汇（open-vocabulary）
  - 以物体为中心（object-centric）的导航流水线。

## 2. 方法论

### 2.1 核心思想

将每个物体标签映射为一个"房间概率向量"（Room Probability Vector, RPV），用目标物体与检测物体 RPV 分布的重叠度（点积）表示其空间共现概率，再将该信号通过测地线洪水填充传播到值图，用于前沿（frontier）语义评分与选择。

### 2.2 感知流水线（Perception Pipeline）

1. **背景掩蔽**：用 Mask2Former（ADE20K 训练）对图像做语义分割，将"floor、wall、ceiling"及"door、window、curtain"等无导航判别力的结构类区域模糊化，抑制下游误检。
2. **开放词汇检测**：在掩蔽后的图像上运行 YOLOE 开放词汇检测器，使用 LVIS 数据集的 1203 个类别作为无过滤候选列表，保留置信度 > 0.5 的检测结果。
3. **高精度分割验证**：将检测到的标签作为 prompt 输入 SAM 3，获得像素级精确掩码，过滤误检；目标类别始终加入 prompt 列表，实现即时目标识别。最终从掩码提取物体质心，结合深度图投影到世界坐标。

### 2.3 房间介导共现模型

- **房间词典**：R = {bathroom, bedroom, dining room, garage, kitchen, hallway, laundry, living room, home office}（共 9 类，可替换/扩展，无需重新训练）。
- **RPV 计算**：对物体 o，计算其 CLIP 文本嵌入与每个房间标签嵌入的余弦相似度，再经温度缩放 softmax：

  \[
  p_o(r_i) = \frac{\exp(s_o(r_i)/\tau)}{\sum_{j=1}^K \exp(s_o(r_j)/\tau)}
  \]

  其中 \(\tau = 0.03\)，得到 RPV \(p_o = [p_o(r_1), \ldots, p_o(r_K)]^\top\)，表示该物体与各类房间的关联概率分布。

- **共现评分**：将 RPV 视为类别分布参数，检测物体 \(o_d\) 与目标物体 \(o_t\) 的共现分数为两者 RPV 的点积（即联合概率 \(P(X_{o_d} = X_{o_t})\)）：

  \[
  A_o = p_{o_d} \cdot p_{o_t} = \sum_{i=1}^K p_{o_d}(r_i) \cdot p_{o_t}(r_i)
  \]

  该度量使分布重叠大的物体对得分高，功能无关的对象对自然被抑制。

### 2.4 信号传播

- **测地线值图**：每个检测物体向值图发射空间衰减信号，使用**快速行进法（FMM）** 进行洪水填充，确保信号沿自由空间传播、不穿透墙壁。值图叠加公式：

  \[
  V(x) = \frac{1}{|O_x|} \sum_{o \in O_x} A_o \cdot \exp\left(-\frac{d_{\text{geo}}(x, x_o)^2}{2\sigma_o^2}\right)
  \]

  其中 \(d_{\text{geo}}\) 是测地距离，归一化求和防止物体密度偏置。

- **自适应 σ**：对共现分数取平方根 \(w = \sqrt{A_o}\)，用于调整信号幅度与空间扩展范围：高相关物体传播更广（\(\sigma\) 在 1.0m–5.0m 间线性插值），低相关物体仅产生局部影响。

### 2.5 前沿选择

- 提取自由/未知空间边界上的前沿，聚类为候选区域。
- 取每个前沿区域值图的中位数作为语义分数，选择最高分前沿作为下一步航点，由预训练 PointNav 控制器驱动。

## 6. 主要结论与发现

1. RPV 点积在 Top-5 锚定相关性（Spearman \(\rho = 0.319\)）、Recall@5（0.524）和 NDCG@5（0.715）上均优于其他分布度量，表明它能有效识别与目标最可能共现的物体子集。
2. 完整流水线（RPV-V2）在零样本、免训练方法中达到最优：SR=0.539、SPL=0.307，相对 VLFM（SR=0.523、SPL=0.303）分别提升 **+3%** 和 **+1.3%**。
3. 相比图像整体（image-holistic）方法，以物体为中心的语义信号提供了更精确的空间定位，无需 prompt 工程或 LLM。
4. 测地线传播（FMM）虽在数值增益上较小（SR +0.005），但保证了信号与可通行空间拓扑一致，避免跨墙泄漏。
5. 在 SPL 上优于需要大量训练数据的 PIRLNav（0.307 vs 0.271）和 L3MVN feed-forward（0.255），说明基于几何约束的语义引导能产生更直接的路径。

## 7. 优点

- **免训练与零样本**：无需任务微调，天然支持任意自然语言目标类别。
- **思想简洁有效**：用房间作为物体的"功能上下文"中介，缓解了原始嵌入相似度与空间共现之间的鸿沟，逻辑清晰、可解释性强。
- **无 prompt 工程**：直接使用原始类别名，避免了 VLFM/UIAP-OGN 中对模板提示的敏感性。
- **计算高效**：感知只需每三步运行一次，平均每步 335.5ms，适合机器人实时部署；无需 LLM 推理。
- **工程细节扎实**：背景掩蔽减少误检、SAM 3 交叉验证过滤假阳性、FMM 确保拓扑一致性、归一化防止物体密度偏置、自适应 σ 区分强/弱语义信号。
- **独立于模型的度量验证**：先验证 RPV 点积与真实共现数据的相关性，再应用于导航，论证链条完整。

## 8. 不足与局限

- **不支持多楼层**：基于 2D 映射框架，无法解决 HM3D 中 14.6% 需要跨楼层导航的 episodes，直接限制了成功率上限。
- **熵未显式建模**：高熵物体（如 chair、table 的多房间分布）会稀释信号，方法依赖平方根变换缓解，但未从根本上解决；论文在展望中承认熵感知剪枝是未来方向。
- **共现相关性较低**：RPV 点积与真实共现数据的全行 Spearman 相关仅为 0.329，虽然排名靠前的锚定效果好（Recall@5 0.524），但整体可靠性有限，存在信号噪声。
- **探索不均衡**：纯语义开发策略在语义稀疏区域（如走廊）可能过度承诺弱信号，缺乏信息增益驱动的探索，导致路径效率下降。
- **评估范围有限**：仅在 HM3D 单数据集、6 类目标上验证，未覆盖更广泛场景（其他数据集或真实机器人）；对失败模式（如不同起始位置、场景类型）缺乏细致分析。
- **复现成本**：集成 Mask2Former、YOLOE、SAM 3、CLIP 等多个大模型，虽免训练但感知栈推理开销高（335.5 ms/步），实际部署需边缘服务器支持。
- **对检测质量敏感**：感知漏斗依赖 YOLOE 召回和 SAM 3 验证，若检测漏掉关键锚定物体（或误检混淆物体），导航信号将受到直接影响。

## 摘要
视觉-语言-动作（VLA）模型作为机器人操作的一种可扩展方法，已引起越来越多的关注。虽然这些模型是有效的动作预测器，但将它们部署为机器人智能体时暴露了关键缺陷：缺乏失败恢复机制、长时程执行不一致，以及对观察、任务或具身变化的鲁棒性有限。现有解决方案通过模型重训练或环境特定模块单独解决这些局限，然而所需的是一个通用框架，能够系统地将预训练的VLA转化为机器人智能体。我们提出了RoboBRIDGE，一个模块化框架，它在五个协调模块（即Monitor、Perceptor、Planner、Controller和Robot Interface）之上提供编排层，从现成组件（包括预训练的VLA）组合出稳健的机器人智能体。Monitor将快速失败检测与分层恢复相结合，在错误级联之前进行纠正。当环境偏离当前计划时，Planner触发重新规划，同时Perceptor异步更新场景理解，避免执行停顿。在Controller内部，原语技能微调将操作分解为具有专用LoRA适配器的域不变原语，从而在使用VLA时降低对域偏移的敏感性。在跨越多个机器人平台和VLA主干的LIBERO、RoboCasa和真实世界案例研究中，RoboBRIDGE始终优于独立策略和先前增强的VLA部署。这些结果表明，可靠的机器人智能体并非仅来自扩大动作预测器的规模，而是来自围绕它们的结构化编排。

## Abstract
Vision-Language-Action (VLA) models have attracted growing interest as a scalable approach to robotic manipulation. While these models are effective action predictors, deploying them as robotic agents exposes critical gaps: no mechanism for failure recovery, inconsistent execution over long horizons, and limited robustness to shifts in observations, tasks, or embodiments. Existing solutions address these limitations individually through model retraining or environment-specific modules, yet what is needed is a general framework that systematically transforms a pretrained VLA into a robotic agent. We present RoboBRIDGE, a modular framework that provides an orchestration layer over five coordinated modules, namely Monitor, Perceptor, Planner, Controller, and Robot Interface, to compose robust robotic agents from off-the-shelf components, including pretrained VLAs. The Monitor pairs rapid failure detection with hierarchical recovery to correct errors before they cascade. When the environment diverges from the current plan, the Planner triggers replanning while the Perceptor updates scene understanding asynchronously, avoiding execution stalls. Within the Controller, primitive skill fine-tuning factors manipulation into domain-invariant primitives with dedicated LoRA adapters, reducing sensitivity to domain shifts when a VLA is used. Across LIBERO, RoboCasa, and real-world case studies spanning multiple robot platforms and VLA backbones, RoboBRIDGE consistently outperforms both standalone policies and prior augmented VLA deployments. These results suggest that reliable robotic agency does not arise from scaling action predictors alone, but from structured orchestration around them.

## 2. 论文提出的方法论

**核心思想：**

将 VLA（或任何动作生成策略）作为可插拔的 Controller 组件，围绕其构建五个协调工作的模块，在不重训练基础模型的前提下提供代理能力。

**五个模块：**

| 模块 | 功能 |
|------|------|
| **Monitor** | 闭环监控执行结果，检测失败并触发分层恢复 |
| **Perceptor** | 将原始传感器观测转换为以物体为中心的语义状态（身份、3D 位姿、属性） |
| **Planner** | 将语言指令分解为有序的原语技能序列，并在环境偏离时触发重规划 |
| **Controller** | 由动作生成策略占据的插槽，将每个原语转化为底层动作 |
| **Robot Interface** | 抽象机器人特定的 API、时序、安全限制和坐标变换，实现跨平台互通 |

**三个关键技术机制：**

### (a) 两阶段监控（Two-phase Monitoring）

- **第一阶段：轻量成功检查**。用一个轻量级模型 \(D_{check}\) 周期性评估当前观测 \(o_t\) 与计划上下文 \(c_t\)，输出二元成功标志 \(suc_t\) 和置信度 \(conf_t\)。采用受限输出格式抑制冗长推理，降低延迟。
- **第二阶段：失败诊断与恢复**。当 \(suc_t = false\) 且 \(conf_t \geq \gamma_{thresh}\) 时，立即停机并调用诊断模型 \(D_{diag}\) 推断根因，输出恢复目标 \(r_t\)，对应四级分层恢复策略：
  1. **retry**：重新执行当前原语（最小代价）；
  2. **regenerate**：保留当前计划和感知状态，重新生成轨迹；
  3. **replan**：基于最新异步感知结果重新规划；
  4. **re-perceive**：强制重新感知后再规划（深度恢复）。

### (b) 异步感知与发散触发重规划（Reactive Planning with Asynchronous Perception）

- 感知与执行解耦为生产者-消费者双线程，通过线程安全缓冲区 \(B\) 通信，感知延迟被执行过程隐藏。
- 每个原语执行完后，计算当前计划所用感知快照 \(\bar{o}_{plan}\) 与缓冲区最新结果 \(\bar{o}_{lat}\) 之间的发散度量：

\[
\Delta(\bar{o}_a, \bar{o}_b) = \max_{i \in O_a \cap O_b} \left[ \|p^{(i)}_a - p^{(i)}_b\|_2 \right] + \lambda \cdot |O_a \triangle O_b|
\]

- 当 \(\Delta \geq \tau\) 时，保留高层动作序列（如 PICK → PLACE），仅基于最新感知重新生成当前及后续原语的底层技能参数。该设计避免冗余的高层推理，只更新空间参数。

### (c) 原语技能微调（Primitive Skill Fine-tuning）

- 将操作分解为域不变原语集合 \(P = \{MOVE, GRIP, ROTATE, \dots\}\)。
- 为每个原语在冻结的 VLA 主干上挂载独立的 LoRA 适配器 \(\Delta\theta_k\)：

\[
f_{\theta + \Delta\theta_k}: (i, s_t, p_t) \mapsto a_t^{(k)}
\]

- 控制器切换采用两级解析器：原语有专用适配器则使用之，否则使用所有已注册 LoRA 适配器的平均值：

\[
RESOLVE(p_t) = \begin{cases}
\Delta\theta_{p_t} & \text{if adapter exists} \\
\frac{1}{|P|} \sum_{p \in P} \Delta\theta_p & \text{otherwise}
\end{cases}
\]

- 动作生成为 7-DoF delta 动作 \(a_t = \langle \delta x, \delta\phi, g \rangle\)，通过笛卡尔速度命令或 IK 求解器两种路径执行。

## 6. 论文的主要结论与发现

1. **RoboBRIDGE 一致性地提升了所有被测试 VLA 主干的表现**：
   - LIBERO 上平均成功率从 35.5% 提升至 39.7%（+4.2 个百分点）。
   - RoboCasa 上从 3.7% 提升至 7.5%（+3.8 个百分点）；排除 pick-and-place 任务后从 6.2% 提升至 11.4%。
   - 无需扩大模型规模或重训练基础策略。

2. **监控比规划对提升更关键**（表 III）：无监控时各 LLM 主干的表现差距很小（1.8–8.0%）；加入监控后差距显著拉开（Claude Opus 4.6 达 14.7%，而 Gemini-3 Flash 仅 2.7%），说明失败诊断需要足够的推理能力。

3. **框架对控制器类型有普适性**（表 IV）：LoRA 微调 + RoboBRIDGE（27.1%）接近全量微调独立部署（31.9%），但更新参数少得多；全量微调 + RoboBRIDGE 进一步升至 40.0%；经典 IK 控制器在框架内也能达到 22.1%。

4. **模型内部自纠正不足以替代外部编排**：CycleVLA 将自纠正集成到模型内部，独立部署仅达 7.5%，远低于 RoboBRIDGE 的表现。

5. **两个主要失败模式**：感知错误（遮挡、相似物体导致位姿误估）和不可恢复的接触丰富操作失败（环境状态被不可逆改变，重试无意义），为后续研究指明方向。

## 7. 优点

- **策略无关的设计**：框架对控制器形式没有假设，VLA、经典 IK 控制器均可接入，通用性强。
- **极简改动成本**：无需重训练基础模型，通过 LoRA 适配器切换即可实现跨域适应，参数效率高。
- **异步感知设计**：将感知延迟隐藏在执行的"阴影"下，重规划仅在场景实质偏离时触发，兼顾实时性和计算效率。
- **分层恢复机制**：从 retry 到 re-perceive 四级递增的恢复代价，既避免不必要的重计算，也支持深度恢复。
- **两阶段监控的设计合理**：轻量检查器持续运行不阻塞控制；详细的失败诊断只在失败发生时调用，效率与深度兼顾。
- **类比 LLM 演进提供了强说服力**：将 VLA 的瓶颈定位为"编排层缺失"而非"策略能力不足"，论述清晰。
- **广泛的主干覆盖**：在轻量（SmolVLA）、规模（π0.5）、SOTA 通用模型（GR00T-N1.5）上均验证了有效性。
